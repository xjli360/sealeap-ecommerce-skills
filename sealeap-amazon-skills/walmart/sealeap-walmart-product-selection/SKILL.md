# Walmart 市场与商品选择

将任务转化为有证据、成本边界和验证办法的经营决策。来源研究日期：2026-09-23；使用时核验所在站点当前规则。

## 输入

目标Walmart国家、商品规格与标识、品牌/供货权利、同规格竞品、净售价、采购/包装尺寸重量、WFS或自发货报价、周期与现金上限。

## 工作流

1. 按真实商品ID、包装件数、规格、成色和履约方式建立竞品集合。区分平台自营、品牌、授权卖家及其他报价，不能拿多件装和单件装直接比价。
2. 在Walmart站内找需求证据和目录缺口，再用其他平台趋势辅助。跨平台销量不能直接视为本平台需求。
3. 检查价格、库存、配送承诺、内容与用户反馈；W01 支持先评估商品转化准备再投入广告，不能用“竞争比别的平台少”代替研究。
4. 用 W03 的季节日历思路倒推到货和清货节点；其历史品类清单不作为今年热销预测。
5. 分别测算WFS和自发货的常态成本、补货现金及退货；临时免仓储/佣金优惠单列情景，不用于证明长期盈利。
6. 先打样与小批测试，再按真实留存订单、单位贡献和库存周转决策。未知销售估算、目录控制权或成本时 HOLD。

## 交付

同规格市场对比、需求证据等级、WFS/自发货单位经济、季节到货计划、首批测试上限与GO/HOLD/NO-GO。
