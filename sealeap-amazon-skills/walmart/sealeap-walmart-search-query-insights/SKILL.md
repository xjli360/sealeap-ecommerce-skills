# Walmart 搜索排名与查询份额

## 任务与输入

报告类型、窗口、商品类型/变体组、排名和份额字段。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 保存报告范围，分别解释Sales rank、funnel rank和query级字段。
2. 区分查询频次排名与该词对某商品的重要性，不混比较集合。
3. 份额只表示竞争集合占比，缺事件数不计算CTR/CVR。
4. 把异常转成相关性、报价、图片或可售检查，再设计单项测试。

## 判断与交付

交付：指标字典；查询诊断；待核假设。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
