# Walmart WFS 包装与标签预检

## 输入与范围

- 商品身份、可售单元和套装关系。
- 目标shipment、目的仓和实际承运方式。
- 商品特性、包装测试及当期类目要求。
- 单品标签、收货标签、承运标签与原始计划。

先固定目标市场、观察时间与用户要作的决定。缺少决定性资料时完成可确定部分，把其余标为未知或HOLD，不虚构账户状态。

## 工作流程

1. 先确认每个可售单元的边界及商品特性，查包装和安全标识的当前要求；未知特殊属性先补证。
2. 分别核单品识别、仓库收货匹配和承运地址三类标签，不把其中一种替代另两种。
3. 检查扫描可读性、标签对应关系、包装遮挡、套装与箱/托盘层级，使用用户真实计划生成的标签。
4. 按自选与平台承运方式核谁提供承运标签、交接和追踪；旧视频尺寸重量不直接写成当期限制。
5. 输出缺陷与修复单，预检通过仅表示所检条件通过，不能证明已发出、已接收或上架。

## 交付

- 可售单元包装清单。
- 三类标签对应表。
- 缺陷/修复与复检。
- 承运交接资料。

分支判断、验收字段和合成案例见 [操作手册](references/playbook.md)；需要查来源范围、计数或当前规则时读 [证据与规则](references/evidence.md)。

## 执行边界

本Skill提供任务流程，不表示已经连接平台或取得商户操作权限。事实、估算、假设、未知分别记录；经验与模型输出不保证收益。只执行用户已授权动作，已有明确授权不重复索取；提交、处理和结果回读分开。网络和工具受限时完成可审阅方案，不绕过访问限制或伪造执行成功。
