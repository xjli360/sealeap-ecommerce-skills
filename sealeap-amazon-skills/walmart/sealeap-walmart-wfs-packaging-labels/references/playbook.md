# 操作手册

以下分支、数据字段和合成案例为M（模型独立综合）；E与R的有限支持范围见 [证据文件](evidence.md)。

## 分支判断

| 观察情况 | 下一步 | 必须避免的误判 |
| --- | --- | --- |
| 商品标签与库存身份不一致 | 暂停该单位放行，核SKU/GTIN | 不能自行换成其他平台标识 |
| 有承运面单但无收货标签 | 标记仓库匹配缺口 | 地址正确不代表可顺利收货 |
| 特殊包装未知 | 查当期指南或平台反馈 | 不能用普通纸箱模板替代所有品类要求 |

## 交付工作表

| 交付项 | 必须保留 |
| --- | --- |
| 可售单元包装清单 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 三类标签对应表 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 缺陷/修复与复检 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 承运交接资料 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |

每个状态都写观察时间；没有发生的动作使用“拟议/待核”，不能写“已完成”。公开报告用匿名代号，原始账户、订单和客户资料留在用户授权范围内。

## 合成案例

### 场景1

输入：同一箱装多SKU但只贴一个商品条码。

应有处理：核箱级与商品级标签，不能认为一个码覆盖全部。

### 场景2

输入：套装按一件销售但组件散装。

应有处理：核当前套装包装和标记规则后再放行。

### 场景3

输入：检测了标签格式但没测试扫描。

应有处理：标可读性未验收，不给完整通过。


## 验收与停止

逐项检查交付是否能追到输入事实。遇到身份不匹配、决定性字段缺失、许可不足或超出用户授权时，停止受影响动作，列明补证与可继续部分。对批量变更保留目标清单、前后值、作用范围和恢复办法；单次请求成功不替代实际结果。
