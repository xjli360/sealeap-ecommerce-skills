# Walmart Connect 广告与利润

将任务转化为有证据、成本边界和验证办法的经营决策。来源研究日期：2026-09-23；使用时核验所在站点当前规则。

## 输入

国家与广告账户范围、商品可售/Buy Box/库存/配送、活动与搜索词报表、广告位、归因窗口、订单净贡献、预算及最大损失。新账户先核验当期资格和实际可用工具。

## 工作流

1. 先查商品、Buy Box、库存、配送与页面信息是否准备好（R13）；不靠加价解决不可售或明显商品缺陷。
2. 根据数据阶段选择自动探索或手动管理。W02 支持清楚命名和相似商品分组，W01 支持阶段化复盘。
3. 自动活动用来发现有效商品/流量线索；手动活动根据已观察搜索意图与利润测试。后台不支持的否词、匹配或广告位控制不能假装存在。
4. 将品牌/非品牌、商品、关键词、匹配与广告位分开看，再按订单去重和成熟归因窗口核算贡献。高ROAS不证明高增量。
5. 用可承受CAC与CVR情景约束CPC，设置预算与累计损失上限。官方推荐日预算和第三方固定溢价均不作为必须执行值。
6. 一次改变一个主要变量；库存或Buy Box变化需记录为干扰因素。明确授权后执行并回读；否则交付可审阅的变更方案。

## 交付

零售准备检查、活动结构与关键词/商品诊断、CPC与预算边界、广告位测试、订单贡献和变更回读表。

## 证据与执行边界

网络来源只支撑参考文件列出的有限方法；其余步骤、公式、示例和决策条件是 M（模型综合设计），不是作者原话、平台保证或已验证业绩。事实、估算、假设、未知分开记录；互动量不证明经营效果。

仅在用户已授权范围内执行。诊断请求不自动授权投放、采购、上架或联系他人；已明确授权无需重复征求同一许可。执行时保留目标、前后值、结果与回读证据。工具不可用时完成数据模板和方案，不伪造后台操作成功。
