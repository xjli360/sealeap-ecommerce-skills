# Walmart 商品组合与竞争空缺

## 任务与输入

同任务竞品、规格/数量、价格配送、可见反馈及供应能力。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 按规格与包装数量归一化样本，区分商品和同一商品不同卖家报价。
2. 找实际未满足任务，不把搜索空白直接认定蓝海。
3. 核差异带来的制造、履约、退货和内容表达成本。
4. 优先打样验证一个缺口，列需求不存在的反证条件。

## 判断与交付

交付：组合地图；差异候选；打样与需求任务。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
