# Walmart 广告与订单贡献对账

## 任务与输入

活动/商品/广告位报告、订单净额、退款、费用与库存/Offer变化。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 固定时区、币种、归因窗口和商品ID映射，区分报表收入与结算收入。
2. 按订单/商品去重并桥接退款、税运费及跨商品归因差异。
3. 逐SKU扣非广告成本和真实广告费，检查收入结构改变。
4. 报告已对平/未对平部分和有限预算方案，不能把ROAS当净利润。

## 判断与交付

交付：广告到账单桥接；SKU贡献；差异与预算建议。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
