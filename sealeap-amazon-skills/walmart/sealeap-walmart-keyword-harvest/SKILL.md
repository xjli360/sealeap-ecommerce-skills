# Walmart 搜索词迁移与关键词验证

## 任务与输入

真实搜索词/商品报告、词意图、成熟订单、贡献、可用控制。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 核词来自真实报表还是工具建议，冻结窗口与商品映射。
2. 按语义和规格判断适配，偶然成交也不能让错误词自动通过。
3. 结合数据量、退货和贡献形成有限手动测试，注明CVR不确定。
4. 按实际支持的匹配/否词处理，保留迁移后交付与费用回读。

## 判断与交付

交付：词证据表；迁移候选；出价情景和复盘。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
