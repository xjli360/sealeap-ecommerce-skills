# 操作手册

以下分支、数据字段和合成案例为M（模型独立综合）；E与R的有限支持范围见 [证据文件](evidence.md)。

## 分支判断

| 观察情况 | 下一步 | 必须避免的误判 |
| --- | --- | --- |
| Delivered但仍Receiving | 检查进度和异常 | 不能直接将差额计为最终损失 |
| Completed且有缺收 | 核符合当前Investigate/Support条件 | 完成状态本身不保证索赔成立 |
| 将近申诉期限但未完成 | 做时效提示与支持询证准备 | 不能把等待建议写成错过期限的理由 |

## 交付工作表

| 交付项 | 必须保留 |
| --- | --- |
| 五阶段数量桥接 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 异常分类与证据清单 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 期限和下一步 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 工单/争议草稿与结果记录 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |

每个状态都写观察时间；没有发生的动作使用“拟议/待核”，不能写“已完成”。公开报告用匿名代号，原始账户、订单和客户资料留在用户授权范围内。

## 合成案例

### 场景1

输入：发出50、目前收到30且仍Receiving。

应有处理：保留20为在收货差异，不立刻认定丢失20。

### 场景2

输入：Completed后短收且两个箱标重复。

应有处理：先解释标签及收货匹配问题，不能保证全额赔付。

### 场景3

输入：返还或处置是平台拟议选项。

应有处理：列明影响与用户授权要求，不擅自同意。


## 验收与停止

逐项检查交付是否能追到输入事实。遇到身份不匹配、决定性字段缺失、许可不足或超出用户授权时，停止受影响动作，列明补证与可继续部分。对批量变更保留目标清单、前后值、作用范围和恢复办法；单次请求成功不替代实际结果。
