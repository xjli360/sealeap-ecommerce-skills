# Walmart 价格监控与利润响应

## 任务与输入

同商品/规格快照、可售、运费、配送、价格底线和库存。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 统一包装数量、币种、含运费报价和服务条件。
2. 区分促销、缺货恢复、换卖家和真实长期降价。
3. 以贡献下限与库存目标决定观察或有限跟价，不自动追最低价。
4. 记录前后设置、影响商品及回退，复盘订单贡献和Buy Box变化。

## 判断与交付

交付：可比价格快照；响应规则；改价验收。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
