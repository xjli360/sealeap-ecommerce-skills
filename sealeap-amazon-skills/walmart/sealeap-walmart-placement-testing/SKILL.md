# Walmart 广告位与加价测试

## 任务与输入

账户可用广告位、倍率计算、CPC/CVR、商品贡献、预算与库存。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 核当期版位定义和加价计算，列可能叠加后的成本情景。
2. 同商品与窗口比较版位意图、净订单、退货和贡献。
3. 一次测试一个主要倍率或版位选择，记录流量和商品组合变化。
4. 达到损失边界或库存/Offer异常时停止，复盘再决定扩大。

## 判断与交付

交付：版位对比；最大成本情景；单变量实验。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
