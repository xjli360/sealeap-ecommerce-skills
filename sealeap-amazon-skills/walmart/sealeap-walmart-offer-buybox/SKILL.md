# Walmart Offer 与 Buy Box 准备

## 任务与输入

同商品卖家报价、总价、配送承诺、库存、卖家绩效和前台状态。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 确认正在比较同一目录商品/变体和当前市场。
2. 核可售、价格、运费、交期、库存与店铺表现，保留时间点。
3. 区分内容问题和Offer竞争，按可证实缺口提出改善。
4. 回读实际前台报价与可售状态，再考虑扩大广告。

## 判断与交付

交付：Offer对照；零售准备检查；改善验收。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
