# Walmart 退货、库存与结算对账

## 任务与输入

订单行、退货原因、物流/仓库状态、退款、调整与结算。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 按订单行对齐发货、退款、退回、检验和重新可售状态。
2. 核回收价值、处理/移除费用及平台调整，防止重复扣损失。
3. 将未对平分为时间差、身份错配、状态缺失和待询证。
4. 回填质量、包材、描述或履约改进；申诉只凭真实证据。

## 判断与交付

交付：退货状态桥接；费用差异；改善与询证清单。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
