# 预算节奏与商品分配判断与验收

## 数据到判断

从 `MPstats 细分/查询趋势与内部SKU贡献；Ozon预算周期/消耗` 取得 需求趋势、实际周期起止、剩余预算、净贡献、库存覆盖、预算模式。先固定样本、SKU/模型映射和分析周期，再执行主流程；保存被排除的行与原因。原始表的字段或时间口径改变后，旧分析不可直接复用。

本任务判定：预算没花完不构成必须加价的理由；未授权不得改为不限额。

## 输出结构

| 区块 | 必填内容 |
| --- | --- |
| 范围 | 地区、模式、SKU/细分、分析日期与覆盖率 |
| 证据 | MPstats报表/原始字段/数据时间/行键；实际与估算分开 |
| 判断 | 活动周期表、SKU预算分配、需求与供给依据、变更及回退条件 |
| 反证 | 哪个观察会推翻判断，缺什么数据会改变结论 |
| 行动 | 优先级、负责人、依赖、损失上限、复查日；需要写入时列明对象 |

没有强制填满所有判断：关键字段缺失时保留 UNKNOWN；明确请求报表名、日期、列和账户范围，方便补数。不可使用模型生成的行业平均值冒充 MPstats 查询结果。
