# 主图与富内容改进简报判断与验收

## 数据到判断

从 `可比 SKU 的图片/评论、价带、关键词与日序列` 取得 可比规格、购买疑问、图片信息、评分变化、价格/在库状态。先固定样本、SKU/模型映射和分析周期，再执行主流程；保存被排除的行与原因。原始表的字段或时间口径改变后，旧分析不可直接复用。

本任务判定：MPstats热销不能证明某张图片有效；没有自身对照不得宣称转化提升。

## 输出结构

| 区块 | 必填内容 |
| --- | --- |
| 范围 | 地区、模式、SKU/细分、分析日期与覆盖率 |
| 证据 | MPstats报表/原始字段/数据时间/行键；实际与估算分开 |
| 判断 | 逐图简报、所解决问题、文案事实、原创素材要求、单变量试验和验收项 |
| 反证 | 哪个观察会推翻判断，缺什么数据会改变结论 |
| 行动 | 优先级、负责人、依赖、损失上限、复查日；需要写入时列明对象 |

没有强制填满所有判断：关键字段缺失时保留 UNKNOWN；明确请求报表名、日期、列和账户范围，方便补数。不可使用模型生成的行业平均值冒充 MPstats 查询结果。
