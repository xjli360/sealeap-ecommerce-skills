# 经营周报与异常归因判断与验收

## 数据到判断

从 `外部 SKU/细分日序列；内部 Товары；广告和结算报告` 取得 订单量、实际收入、贡献、库存、价、评分、关键词、市场同窗变化。先固定样本、SKU/模型映射和分析周期，再执行主流程；保存被排除的行与原因。原始表的字段或时间口径改变后，旧分析不可直接复用。

本任务判定：没有实际订单与成本只能交市场观察；无因果证据不宣布是广告或算法造成。

## 输出结构

| 区块 | 必填内容 |
| --- | --- |
| 范围 | 地区、模式、SKU/细分、分析日期与覆盖率 |
| 证据 | MPstats报表/原始字段/数据时间/行键；实际与估算分开 |
| 判断 | 一页经营结论、指标桥、市场对照、异常假设、行动与验证清单 |
| 反证 | 哪个观察会推翻判断，缺什么数据会改变结论 |
| 行动 | 优先级、负责人、依赖、损失上限、复查日；需要写入时列明对象 |

没有强制填满所有判断：关键字段缺失时保留 UNKNOWN；明确请求报表名、日期、列和账户范围，方便补数。不可使用模型生成的行业平均值冒充 MPstats 查询结果。
