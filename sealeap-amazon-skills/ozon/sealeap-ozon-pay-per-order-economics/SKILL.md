# OZON 订单付费与组合推广经济性

## 任务与输入

结合 MPstats 评估 OZON 按订单付费与 CPC 组合推广是否有净贡献。必要输入：当前账户费率/资格、SKU/模型对应、广告前成本、单独与组合推广方案。

先确认卖家注册地区、目标市场、跨境/本土模式和分析时间；中国跨境与俄罗斯本土账户的资格、费率、履约和推广入口不能互相套用。

## MPstats 必需输入

- 报表/能力：MPstats 内部商品贡献与外部价带；Ozon PPO/组合模式明细。
- 字段：PPO费率及基数、CPC花费、模型销售范围、退款、奖金、卖家收入。
- 先按 [MPstats接入与口径](references/mpstats.md) 取得并验收数据，保留原始字段和时间范围。没有数据时输出 HOLD 与具体补数请求，不输出已验证业务结论。

## 执行

1. 从当前后台记录选定商品/全店、单独PPO/组合模式各自计费规则，费率不从旧教程固定。
2. 用MPstats价带核对售价竞争力，用内部成本识别可承受的订单推广成本。
3. 将PPO费用与CPC花费分别计入同一订单经济情景，不能看到组合优惠就忽略另一项费用。
4. 核对模型其他变体的订单、取消、退款和费率切换日期，避免分母错位。
5. 比较广告后总贡献及现金，输出小范围试验或停止提案。

## 决策与交付

折扣费率不是利润提升证明；SKU/模型收入和计费基数不清为HOLD。

交付：模式对照、计费桥、组合贡献情景、变体覆盖、试验上限和对账任务。每项结论带 MPstats 证据定位、计算式/判断条件、FACT / ESTIMATE / ASSUMPTION / UNKNOWN、限制和下一步。只交可复核方案；外部写入需用户在该任务中授权。
