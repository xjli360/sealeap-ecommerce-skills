# 单位经济与广告承受力判断与验收

## 数据到判断

从 `外部 Цены / SKU 价格；内部 Кабинет Ozon → Товары 成本与扣费` 取得 折后价/卡价、币种、买家/卖家收入、成本、佣金、正逆物流、推广、折扣积分。先固定样本、SKU/模型映射和分析周期，再执行主流程；保存被排除的行与原因。原始表的字段或时间口径改变后，旧分析不可直接复用。

本任务判定：广告前贡献≤0不建议用广告扩量；缺关键扣费/成本为 HOLD，未知不得填0。

## 输出结构

| 区块 | 必填内容 |
| --- | --- |
| 范围 | 地区、模式、SKU/细分、分析日期与覆盖率 |
| 证据 | MPstats报表/原始字段/数据时间/行键；实际与估算分开 |
| 判断 | 成本桥、价带情景、保本广告率、现金缺口、假设敏感性和补证任务 |
| 反证 | 哪个观察会推翻判断，缺什么数据会改变结论 |
| 行动 | 优先级、负责人、依赖、损失上限、复查日；需要写入时列明对象 |

没有强制填满所有判断：关键字段缺失时保留 UNKNOWN；明确请求报表名、日期、列和账户范围，方便补数。不可使用模型生成的行业平均值冒充 MPstats 查询结果。
