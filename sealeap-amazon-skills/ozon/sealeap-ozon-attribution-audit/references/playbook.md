# 站内外广告归因与去重判断与验收

## 数据到判断

从 `Ozon CPC/PPO/外部流量订单明细；MPstats内部销售与外部日序列` 取得 订单行、SKU/model、事件时间、归因窗口、来源、含折扣金额、spend、退款。先固定样本、SKU/模型映射和分析周期，再执行主流程；保存被排除的行与原因。原始表的字段或时间口径改变后，旧分析不可直接复用。

本任务判定：总销售减广告归因不自动等于自然销售；拒绝手工补造归因订单。

## 输出结构

| 区块 | 必填内容 |
| --- | --- |
| 范围 | 地区、模式、SKU/细分、分析日期与覆盖率 |
| 证据 | MPstats报表/原始字段/数据时间/行键；实际与估算分开 |
| 判断 | 口径矩阵、去重键/覆盖、收入与费用桥、未知重叠、可用指标说明 |
| 反证 | 哪个观察会推翻判断，缺什么数据会改变结论 |
| 行动 | 优先级、负责人、依赖、损失上限、复查日；需要写入时列明对象 |

没有强制填满所有判断：关键字段缺失时保留 UNKNOWN；明确请求报表名、日期、列和账户范围，方便补数。不可使用模型生成的行业平均值冒充 MPstats 查询结果。
