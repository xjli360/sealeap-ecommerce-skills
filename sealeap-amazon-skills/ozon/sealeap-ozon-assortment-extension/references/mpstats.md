# MPstats 必需数据约定

本任务必须有 MPstats 的 OZON 数据。没有可用权限或合格导出时，交付补数清单与 HOLD；不能改用模型猜销量后标为完成。

## 接入

1. **已配置 MCP**：先列出真实工具和参数，选择 OZON 外部分析或已授权的内部只读报表。不要发明工具名；外部 Analytics 不等于内部广告管理。
2. **官方 API**：参照 [OZON API](https://mpstats.io/integrations/analytics-oz/) 核对当前方法和字段。令牌只从私有环境读取，以 `X-Mpstats-TOKEN` 请求头发送，不能写进文档、日志、公开仓库或截图。401/403 停止；202 为待完成；429 按服务提示退避，不能无限重试。
3. **文件导出**：在 MPstats 选择 Ozon 和任务所需报表，明确日期/FBS开关，下载全部所需列；记录原始文件哈希、列名、筛选和时间。CSV/XLSX是可接受的接入方式，但不能拿其他来源改名充当MPstats。

内部 `Кабинет Ozon` 必须已连接正确店铺。不要为了本任务自动绑定账号、创建令牌或扩大权限。内部报表导出可补充真实销售/费用；其公开 API 和 MCP 能力需另外确认，不能借外部接口推断存在。

## 数据清单

每份文件记录 `provider=mpstats`、`marketplace=ozon`、`module=external/internal`、卖家地区和经营模式、报表/端点、抓取时间、报告实际起止、时区、币种/金额单位、FBO或FBO+FBS、过滤/分页/覆盖率、SKU粒度及字段映射。排序后取前50只代表样本；未取全不称全市场。

把原始数据与分析表分开保留。结果行带数据清单ID、SKU或细分ID、日期和计算式；记录缺失，禁止把null、破折号、no_data或失败响应填成0。`sku_first_date`是首次发现线索，不能证明首次上架。

## 解释边界

- 外部订单/金额是观察与估算：标 ESTIMATE。自家已核订单与费用标 FACT；自行设定参数标 ASSUMPTION；无法证实标 UNKNOWN。
- 价格区分基础价、折后价、Ozon卡价与卖家收入；未确认金额单位时不做金额运算。不用外部估算计算自家真实利润/广告ROAS。
- FBS开关、日期、区域、商品类型和尺寸SKU必须匹配。可见性与频次是代理指标，不能充当实际广告曝光或点击。
- 先读本任务的字段与决策规则；执行费率、税务、合规和广告资格需在对应地区的最新官方规则/账户中复核。

## 交付验收

至少展示一条从MPstats原始字段到本任务判断的证据链，并列出反例。数据齐全只代表可以分析；发布、调价、投放、采购或联系买家属于另一个明确授权的动作。
