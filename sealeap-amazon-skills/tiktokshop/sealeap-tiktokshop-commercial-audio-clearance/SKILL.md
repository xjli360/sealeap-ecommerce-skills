# TikTok Shop 商用音乐与跨平台素材验收

## 输入与范围

- 素材版本、原声/音乐/音效组成。
- 计划发布平台、地区、自然/付费用途及期限。
- CML条目或独立授权证明。
- 创作者与品牌约定、编辑权和再利用范围。

先固定目标市场、观察时间与用户要作的决定。缺少决定性资料时完成可确定部分，把其余标为未知或HOLD，不虚构账户状态。

## 工作流程

1. 拆分自有口播、背景音乐、采样、其他用户原声和音效，逐层确认权利来源。
2. 商业内容优先检查当前CML或完整独立许可，热门、可下载、静音变速或切换账户均不构成授权。
3. 核具体用途、地区和期限；用CML做TikTok内容不能自动证明可带同一音轨发到其他平台。
4. 为再利用保留无音乐母版和平台特定版本，核每次新增音轨与品牌约定。
5. 交付通过/补证/替换清单及授权记录，不发布音轨原件，不擅自上线或购买音乐许可。

## 交付

- 音轨权利矩阵。
- 平台/地区/用途版本表。
- 补证或替换清单。
- 发布前验收记录。

分支判断、验收字段和合成案例见 [操作手册](references/playbook.md)；需要查来源范围、计数或当前规则时读 [证据与规则](references/evidence.md)。

## 执行边界

本Skill提供任务流程，不表示已经连接平台或取得商户操作权限。事实、估算、假设、未知分别记录；经验与模型输出不保证收益。只执行用户已授权动作，已有明确授权不重复索取；提交、处理和结果回读分开。网络和工具受限时完成可审阅方案，不绕过访问限制或伪造执行成功。
