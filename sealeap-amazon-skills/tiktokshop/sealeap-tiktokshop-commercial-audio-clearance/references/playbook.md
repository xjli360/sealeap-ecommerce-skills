# 操作手册

以下分支、数据字段和合成案例为M（模型独立综合）；E与R的有限支持范围见 [证据文件](evidence.md)。

## 分支判断

| 观察情况 | 下一步 | 必须避免的误判 |
| --- | --- | --- |
| 其他用户标为原创音频 | 核是否含第三方音乐或采样 | 标签不是商用授权 |
| TikTok版本拟转Instagram/YouTube | 核独立跨平台许可或制作合规替代版本 | 不能仅下载原视频跨发 |
| CML可见但用途条件未知 | 保留待核，不推断所有用途都覆盖 | 不把免版税当无版权 |

## 交付工作表

| 交付项 | 必须保留 |
| --- | --- |
| 音轨权利矩阵 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 平台/地区/用途版本表 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 补证或替换清单 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 发布前验收记录 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |

每个状态都写观察时间；没有发生的动作使用“拟议/待核”，不能写“已完成”。公开报告用匿名代号，原始账户、订单和客户资料留在用户授权范围内。

## 合成案例

### 场景1

输入：达人授权视频画面但没有给音乐许可。

应有处理：画面与音轨分开核查，不能整条默认可投放。

### 场景2

输入：同一曲目在个人账户能选到。

应有处理：不据此证明带货广告可用。

### 场景3

输入：要将已带CML音乐的视频跨平台投放。

应有处理：优先核许可，必要时用无音乐母版配适用音轨。


## 验收与停止

逐项检查交付是否能追到输入事实。遇到身份不匹配、决定性字段缺失、许可不足或超出用户授权时，停止受影响动作，列明补证与可继续部分。对批量变更保留目标清单、前后值、作用范围和恢复办法；单次请求成功不替代实际结果。
