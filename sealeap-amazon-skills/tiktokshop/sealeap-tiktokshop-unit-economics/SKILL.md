# TikTok Shop 佣金与内容全成本

## 任务与输入

实际平台费率、订单净额、履约、佣金基数、样品/报酬、广告和售后。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 将同一批已支付发货订单归一到单SKU、单可售单位、单币种；区分折后卖家收入、退款、平台补贴与已扣费结算款。
2. 按实际生效的标准联盟、Shop Ads或非联盟路径建立互斥订单组；Shop Ads回退标准费率时只计一次佣金，核对保护期和退款后的计佣基数。
3. 按 [计算器输入与公式](references/calculator.md) 填齐费用和批次寄样/报酬/制作成本，运行脚本。未知成本不填0，不沿用统一平台费率。
4. 比较单件/总贡献、保本及目标佣金上限、固定当前佣金的广告上限。两种上限不能同时取最大值，必须满足佣金与广告共同预算。
5. 改变售价、退款、销量或营销费用后重跑情景，再核当前平台允许区间、费率联动和生效状态。库存现金占用与到账时间单列，不用贡献利润替代。

## 运行脚本

从本Skill目录运行，无第三方Python依赖：

```bash
python3 scripts/unit_economics.py references/example-scenario.json
```

[合成样例](references/example-scenario.json) 可复制后替换输入；[脚本](scripts/unit_economics.py) 输出JSON。数据不全或口径错误返回HOLD及退出码2，合成结果不作为真实经营证明。

## 判断与交付

交付：输入清单与计算结果；分组及总盘贡献；佣金/投流条件上限与共同预算；平台可设置范围与生效差异；需另核的现金事项。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
