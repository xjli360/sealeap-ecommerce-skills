# TikTok Shop GMV Max 广告诊断

将任务转化为有证据、成本边界和验证办法的经营决策。来源研究日期：2026-09-23；使用时核验所在站点当前规则。

## 输入

国家、Product或LIVE模式、选中商品、活动状态和时间、预算/目标、素材权限与状态、订单/佣金/退款、库存及成本。优先取得当前后台真实字段，不套旧手投界面。

## 工作流

1. 先确认模式、商品和统计范围。按 R09 明确 GMV Max 会归入相应自然和付费订单；报表ROI不是净利润，也不是新增广告ROAS。
2. 检查商品可购、库存、账户资格、余额、活动安排及素材授权。未消耗不是自动证明目标太高，先排除执行条件。
3. 将排队、学习、投放等状态与真实消耗/订单分开看（T02）。不采用固定一美元、48小时或有一单必过学习期等未验证说法。
4. 用商品净贡献反推目标约束，分开商家优惠、平台补贴、达人佣金、退款和广告花费。估算的利润ROI不得冒充平台ROI字段。
5. 预算、目标ROI、素材或商品范围每次改变一项；记录前后值、最大损失、观察窗口、归因延迟和库存约束。
6. 只有数据可信、净贡献改善且履约可承受时建议扩量。降低目标可能增加消耗，不是保证销量；无明确执行授权只交付方案。

## 交付

模式与归因说明、未消耗排查结果、素材权限表、净贡献核算、单变量实验卡和执行/回读状态。
