# TikTok Shop 短视频脚本与测试

## 任务与输入

商品事实、任务、素材许可、内容表现、商品点击与净订单。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 将脚本拆成问题、演示、证据、限制与行动，选一个主要假设。
2. 制作原创角度矩阵，记录不同开头/场景而非重复搬运。
3. 分别看观看、商品点击、支付与留存，保持窗口和商品一致。
4. 复盘可复制要素与误解，保留内容未获相同分发的限制。

## 判断与交付

交付：脚本矩阵；拍摄brief；实验复盘。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
