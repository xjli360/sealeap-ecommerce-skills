# 操作手册

以下流程细化、计算和合成案例均为 M（模型综合设计），来源支持范围见 [证据与规则](evidence.md)。

## 达人协作的业务字段（M）
商品适配、人群/国家、相关内容质量、近期有效带货、样品兑现、授权范围、预期费用、可留存订单贡献。公开GMV常是估算或广告混合结果，必须标明来源；不把创作者身份、联系方式、真实店铺经营数据放进公开报告。
样品不是免费：采购、包装、运输、管理和机会成本均计入。用批准→签收→有效发布→可用授权→成交的漏斗寻找损耗。

## Brief 应包含
目标买家与一个明确场景、已验证产品事实、可演示步骤、禁止夸大的声明、必要披露、交付版本和期限、素材与广告使用权。保留创作者自然表达空间；不要求其伪造使用体验。
直播额外列商品顺序、实际优惠、库存提醒、客服交接和突发缺货处理。不能承诺虚假低价或不存在的库存。

## 运营诊断
| 现象 | 先检查 |
| --- | --- |
| 播放高、商品点击低 | 内容与购买任务是否一致、商品关联是否正确 |
| 点击高、支付低 | 价格、交期、可信展示和详情页 |
| 付费订单升、净贡献降 | 佣金、补贴归属、退货和履约 |
| 样品多、内容少 | 筛选、交付约定与跟进 |
| 素材不可投放 | 授权、可用状态、关联商品与地区资格 |

## 示例（合成）
寄出20件样品，签收18，发布6，广告可用3。应分别报告签收、发布与授权损耗，不能说“20个达人可投放”。
