# TikTok Shop 内容、达人与履约

将任务转化为有证据、成本边界和验证办法的经营决策。来源研究日期：2026-09-23；使用时核验所在站点当前规则。

## 输入

市场、商品和库存、店铺漏斗、内容清单与授权、达人历史合作记录、样品预算、物流表现和售后原因。达人信息只保留任务需要的别名与业务指标。

## 工作流

1. 将商品上架可购、内容发现、商品点击、支付、按时履约、退款后留存订单串成同一漏斗。视频播放与店铺成交使用不同分母。
2. 按内容承诺、产品演示、适用人群和疑虑解答组织原创素材。T04 支持将达人入组和brief纳入运营，而非只追单条播放。
3. 选择 Open/Target 合作模式前核验市场规则和佣金状态；按人群、内容风格、相关商品成交与合作执行质量筛达人，不以粉丝数单独排序。
4. 寄样记录申请、批准、发出、签收、发布、授权、带货及售后；有效内容产出率与可留存贡献比寄出数量更重要。
5. 广告可用素材核对授权主体、商品链接、期限和用途；T02 只提醒不要只盯素材状态。被授权用于自然发布不自动等于可用于广告。
6. 直播/视频放量前检查库存和履约承诺，售后按SKU及原因复盘。交付内容草稿和协作清单；联系达人、发样或改佣金须有明确授权。

## 交付

内容矩阵、达人候选评分依据、brief草稿、寄样漏斗、授权清单、库存/售后问题表与下轮测试任务。

## 证据与执行边界

网络来源只支撑参考文件列出的有限方法；其余步骤、公式、示例和决策条件是 M（模型综合设计），不是作者原话、平台保证或已验证业绩。事实、估算、假设、未知分开记录；互动量不证明经营效果。
