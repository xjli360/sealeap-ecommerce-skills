# TikTok Shop 退货与内容预期

## 任务与输入

匿名退货原因、对应视频/商品页、订单净额、回收与服务记录。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 把产品缺陷、内容误解、尺寸/用途不符与物流问题分层。
2. 按素材、SKU、批次和成熟订单队列观察，避免只用刚成交订单作分母。
3. 核退款后贡献与内容/佣金结算，缺数据给区间。
4. 将根因回填视频、商品卡、包材或服务，准备事实性回复。

## 判断与交付

交付：退货原因矩阵；内容修正；净贡献复盘。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
