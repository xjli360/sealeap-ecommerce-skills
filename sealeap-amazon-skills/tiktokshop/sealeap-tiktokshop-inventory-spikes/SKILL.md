# TikTok Shop 爆量与库存风险

## 任务与输入

可用/预留/在途、内容排期、需求区间、补货周期和现金。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 区分持续自然需求和单次内容峰值，冻结预测所依据的窗口。
2. 按基准、峰值与回落情景计算覆盖，扣除已承诺订单与不可用库存。
3. 比较分批采购、调拨、限量和内容节奏，注明到货可信度。
4. 设置缺货/积压预警及恢复条件，实际写库存前核目标SKU。

## 判断与交付

交付：SKU情景表；补货/限量建议；预警。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
