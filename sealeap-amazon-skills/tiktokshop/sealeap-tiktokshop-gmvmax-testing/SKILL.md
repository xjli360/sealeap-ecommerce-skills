# TikTok Shop GMV Max 目标与预算实验

## 任务与输入

市场可用功能、商品/素材状态、活动目标、全域订单、成本与预算。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 核商品可售、授权素材和当前自动化控制，不套旧手动广告组模板。
2. 区分交付不足与净贡献不足，检查目标、内容供给、库存和报价。
3. 一次主要改变目标、预算或供给之一，预设累计损失与回退设置。
4. 按成熟窗口与经营贡献复盘，记录自然内容、直播和达人发布干扰。

## 判断与交付

交付：诊断表；单变量试验；回退条件。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
