# TikTok Shop 视频挂链与失效商品验收

## 输入与范围

- 站点、商家或创作者角色、实际权限及可见功能；本研究官方规则范围为美国站。
- 视频发布时间、现有商品链接/异常状态、近期互动和原始内容事实。
- 候选商品身份、款式/规格、品牌、关键功能、库存与合作资格。
- 音轨及素材商业使用依据、视频中提及的价格/卖家/功效，以及执行授权。

视频商品关联的操作与验收；演示脚本设计保留在现有短视频测试入口。先固定站点与观察日期；事实、估算、假设和未知分开记录。缺决定性资料时完成可确定部分，把其余列为待核或 HOLD。

## 执行流程

1. 先分辨商品加入橱窗、视频草稿带链接和发布后买家可见的购物入口；三种状态分别取证，不凭橱窗截图判定视频可购。
2. 给任务分流：发布前首链、已发布且原本无链接的补链、已有商品失效的重挂；已有有效链接的任意替换不在默认能力内。
3. 读取目标市场当前规则与账户功能，核对视频时限、互动、异常原因及内容/音轨要求。没有入口不猜隐藏 API，也不通过改地区或借用身份绕过资格。
4. 逐项比较视频与候选商品的外观、品牌、功能、规格、价格和卖家声明。平台推荐只提供候选；不匹配时重新制作内容或保持 HOLD。
5. 形成挂链草稿：目标视频、目标商品、清晰诚实的锚点名称及变更前后值；仅在授权范围内操作并读回处理状态。
6. 从观众可见入口检查目标商品、可售状态和落地信息；重挂后持续检查旧品恢复及多入口状态。点击、订单与佣金结算各自核对，不能凭成功提示保证收益。

## 交付与验收

- 角色与功能资格矩阵。
- 首链/补链/重挂分支记录。
- 视频—商品一致性检查表。
- 买家端挂链验收与后续复查清单。

分支、模板和合成案例见[操作手册](references/playbook.md)；需要核对内容依据与当期规则时读[证据与规则](references/evidence.md)。单个任务只加载所需参考。

## 执行边界

输入、决策流程与案例属于 M（模型综合）；来源不保证经营效果。本 Skill 不表示已连接商户后台。按用户已授权范围执行，已有授权不重复索取；涉及条款或交易的确认按宿主要求处理。提交、处理与实际生效分别验收，工具不可用时交付可审阅方案，不伪造已完成结果。
