## 场景审阅

这是对指南的文本审阅和合成示例核算，没有独立Agent或卖家后台实测。

| 场景 | 必须保留的判断 |
| --- | --- |
| Shopify净收入60、非广告成本39、目标贡献6 | 可承受CAC=15，不靠假设复购抬高 |
| 邮件40点击、1000送达、200打开 | 两项点击指标分别4%与20%，分母明确 |
| Etsy工时高但毛利率好 | 检查每小时贡献、返工和产能，不能只扩单 |
| Etsy历史达过站外广告门槛 | 近期收入下降不能自动获得退出资格 |
| eBay高关注/高在售报价 | 不当订单或实际成交价，补同口径已售 |
| eBay未授权经销、低于建议价 | 不足以直接提交VeRO，核真实知识产权 |
| TikTok寄样签收/自然视频公开 | 不等于出片或获得广告及跨平台许可 |
| TikTok全域收入被多个报表归因 | 订单去重，费用分别核，不把GMV Max当纯增量 |
| Walmart WFS积压与超龄 | 纳入当前仓储费用，纠正免长期仓储费说法 |
| Walmart排名20和100 | 不能算20% CTR；排名、份额与事件率分开 |
