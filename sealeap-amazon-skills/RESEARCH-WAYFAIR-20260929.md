## 未采用的材料

- B站：可读单视频的播放与互动未达门槛；没有拿合集总播放给单视频背书。
- 知乎：读到原文，但可见收藏较少、其他内容级指标未能证明达标，未计入来源。
- 抖音：找到相关内容，索引可见互动不足；未以平台知名度补足证据。
- 公众号：未取得符合要求、可核读且有内容级互动的原文；行业站转载没有冒充公众号原文。
- 行业文章：两篇有用线索缺少达标的篇级互动，作者累计曝光不能替代，未作为 E 来源。
- GitHub：发现接入/采集线索，但没有把工具项目直接当经营方法证据，也未导入其代码或本地 Skill。
- 小红书与 YouTube：部分内容虽然热度足够，但只有宣传标签、缺少可读方法，或将点击当独立人数、ROAS 当利润、混淆 MSRP/MAP、把净回款重复扣费，均被排除。

这些缺口是本轮研究边界，不能解读为相关渠道没有优质内容。互动量只决定是否值得审核，不证明收益、平台机制或作者结论正确。

## 官方规则与纠错

[规则登记 R94–R111](assets/rule-wayfair-20260929.json)记录各页面实际核读范围。官方资料用于定义、责任与执行前核验，不冒充有互动支持的经验来源。

| 容易误判的地方 | 本批采用的处理 |
| --- | --- |
| 供货价、前台零售价、净回款 | 分开建立金额桥，禁止固定乘数倒推利润；按 [供货模式](https://sell.wayfair.com/) 与实际 PO/协议核对 |
| 历史德国扩站教程 | [官方退出公告](https://www.aboutwayfair.com/category/company-news/a-message-from-co-founder-and-ceo-niraj-shah)纠正旧市场信息；销售地区与 CastleGate 仓网覆盖分别核验 |
| 产品、组件、套装和箱数 | 按 [SKU 类型](https://sell.wayfair.com/blog/learn-the-basics/what-is-a-sku)建映射；箱数不是可售数量 |
| Allowance 全包退货 | 对照 [退货方案](https://sell.wayfair.com/operate-returns)及实际条款，区分收入冲减、已覆盖损失与剩余服务成本 |
| CastleGate 签收即可售 | 按 [适用协议](https://sell.wayfair.com/msa)分别跟踪送达、验收、计数和可售；费表与项目条件不硬编码 |
| 广告通用面板与保本 ROAS | 按 [广告产品](https://sell.wayfair.com/grow-advertising)与当前账户确认控制项；不承诺 Amazon 式否词能力，不拿零售归因销售直接证明供货利润或增量 |
| API 返回成功即发货完成 | [Dropship 与 ASN 文档](https://developer.wayfair.io/posts/dropship-orders-asn)区分订单接受、必要注册/面单、实际发运和 ASN；核对最终及行级错误，避免多通道重复处理 |

每个 Skill 还会核对库存、交期、包装、图片与商品声明是否真实。执行时使用当前地区、合同、计划与账户信息；历史视频中的保险金额、付款天数、费率、广告规格与归因窗口没有被写成普遍常数。
