# Etsy 储备金与可用现金诊断

## 输入与范围

- 账户展示的储备比例、持有期及适用日期。
- 匿名订单与Monthly Statement中的状态、可用日期。
- 真实承运追踪、平台同步状态和生产方发货数据。
- 已付生产/运输费用、退款、可用余额与银行到账。

先固定目标市场、观察时间与用户要作的决定。缺少决定性资料时完成可确定部分，把其余标为未知或HOLD，不虚构账户状态。

## 工作流程

1. 先辨认Payment Reserve、支付处理延迟与普通打款安排，不能混成一个冻结原因。
2. 逐单核追踪已上传、承运方已在途、Etsy可确认在途及资金释放四个状态，查供应方连接和数据延迟。
3. 将储备金额、当前余额、可打款与已到账分开对账，预估可用日期不是银行到账承诺。
4. 测算现有订单继续生产/发货需要的现金及退款缓冲，给保守情景，不建议借新订单资金填无限缺口。
5. 对不一致订单准备事实和支持询证材料；不伪造追踪、不保证移除储备，也不擅自改已承诺交期。

## 交付

- 订单-追踪-资金状态桥接。
- 现金需求情景。
- 同步异常清单。
- 支持询证草稿。

分支判断、验收字段和合成案例见 [操作手册](references/playbook.md)；需要查来源范围、计数或当前规则时读 [证据与规则](references/evidence.md)。

## 执行边界

本Skill提供任务流程，不表示已经连接平台或取得商户操作权限。事实、估算、假设、未知分别记录；经验与模型输出不保证收益。只执行用户已授权动作，已有明确授权不重复索取；提交、处理和结果回读分开。网络和工具受限时完成可审阅方案，不绕过访问限制或伪造执行成功。
