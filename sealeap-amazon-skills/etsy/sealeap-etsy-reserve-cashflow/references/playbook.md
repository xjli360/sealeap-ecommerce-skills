# 操作手册

以下分支、数据字段和合成案例为M（模型独立综合）；E与R的有限支持范围见 [证据文件](evidence.md)。

## 分支判断

| 观察情况 | 下一步 | 必须避免的误判 |
| --- | --- | --- |
| 已有追踪但仍被储备 | 核在途扫描及Etsy能否验证 | 面单生成不是在途证据 |
| 资金已从reserve释放 | 核费用扣除、打款门槛和银行状态 | 不把释放等同到账 |
| 储备比例或日期不明 | 以账户当前显示为待补字段 | 不套旧教程固定比例/天数 |

## 交付工作表

| 交付项 | 必须保留 |
| --- | --- |
| 订单-追踪-资金状态桥接 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 现金需求情景 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 同步异常清单 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 支持询证草稿 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |

每个状态都写观察时间；没有发生的动作使用“拟议/待核”，不能写“已完成”。公开报告用匿名代号，原始账户、订单和客户资料留在用户授权范围内。

## 合成案例

### 场景1

输入：POD已扣生产费而Etsy款项尚未可用。

应有处理：记录现金时间差，不把未到账收入当生产预算。

### 场景2

输入：承运网页已在途，平台仍预运输。

应有处理：保留双方状态与时间，不随意换假追踪号。

### 场景3

输入：过去教程承诺某徽章24小时解冻。

应有处理：不采用保证；核当前账户及官方条件。


## 验收与停止

逐项检查交付是否能追到输入事实。遇到身份不匹配、决定性字段缺失、许可不足或超出用户授权时，停止受影响动作，列明补证与可继续部分。对批量变更保留目标清单、前后值、作用范围和恢复办法；单次请求成功不替代实际结果。
