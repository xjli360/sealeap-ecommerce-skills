# 将客户问题转成商品与交付改进

Z01 支持将匿名汇总行为和公开问题组合研究。本手册为 M，将需求线索转为可交付改动；不依赖旧版分析工具集成，见 [证据与规则](evidence.md)。

## 建立问题到动作的对应关系

| 买家问题 | 商品页或流程动作 | 验收方式 |
| --- | --- | --- |
| 不确定尺寸/兼容性 | 真实比例、尺寸图、适用与不适用条件 | 用户能否在下单前选对 |
| 不知道如何提交定制 | 输入示例、可接受格式、确认步骤 | 缺资料订单与返工原因 |
| 担心赶不上场合 | 制作时长、交付承诺与截止条件 | 承诺与实际履约一致 |
| 数字商品不会使用 | 文件类型、软件要求、下载和使用说明 | 下载成功与问题类型 |

只发布能被商品事实支持的承诺，不能把竞争对手的好评写成自己的证言。数字商品与实物交付分别处理；“可定制”不意味着无限修改和零额外交期。

## 将数据不足与问题严重分开

在可用的店铺统计、查询和客户反馈中记录问题，不预设所有外部分析工具都能接入 Etsy。公开评论用于提问；本店实际返工、退款和缺资料记录用于校验。某问题只出现一次时标为个案，若后果严重可先修正说明，但不宣称它造成全部转化损失。

改动前保留同一商品的基线和同期促销/库存信息；每次优先解决一个高影响摩擦。评价改善关注可比较的流量、订单、返工与售后结果，不能仅看搜索排名。

## 可复用交付

输出“匿名问题类别 → 事实依据 → 拟改字段/步骤 → 负责人 → 结果口径”。客户姓名、邮箱、收件地址与订单原文不进入分析手册。对客户发送消息或修改已上线商品需处于用户授权范围；草稿中的占位条件不得当成真实承诺。
