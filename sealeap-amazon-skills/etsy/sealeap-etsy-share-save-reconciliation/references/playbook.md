# 操作手册

本页为独立编写的 M（模型综合）流程与合成案例；网络经验与规则的实际支持范围见[证据文件](evidence.md)。

## 按订单判定

| 条件 | 处理 |
| --- | --- |
| 未参加或暂停参与期间产生点击 | 查当期条款；链接可访问不代表费用优惠有效 |
| 合格平台链接在外部渠道使用 | 进入订单级窗口与归因核验 |
| 链接仅放在 Etsy 站内消息/描述 | 不据此判定合格外部引流 |
| 买家随后点击 Offsite Ads | 按最后点击和当期冲突规则核验，不双重计入优惠 |
| 订单有标签但费用尚未对上 | 区分统计延迟、口径或冲销，保留待核差额 |
| 活动优惠已结束 | 按下单与条款适用时间重算，不沿用首期奖励 |

2026-09-24所读官方页面区分通常规则与新参与者限时活动。执行时重新核验；不要把短期优惠费率、持续时间或默认归因窗口写成所有账户永久常数。

## 账桥

按同币种、同订单范围记录：

- 预计返还 = 合格的费用计算基数 × 此订单适用返还率（仅在条款确为比例制且基数明确时）。
- 差额 = 预计返还 − 账上实际返还；冲销单列，再连接到净额。
- 内容净贡献需要扣除商品、履约、退款、平台费和外部获客投入；费用节省不能直接称为净利润。

税、运费、礼品包装及退款对计算的影响由当前条款和账目决定；不要混用买家支付总额、银行到账和交易费用基数。比较窗口需允许平台处理延迟，未知返还保持空值，不填零。

## 易错场景（合成）

1. 短视频链接带来访问，之后买家最后点击站外广告。不能同时估算 Share & Save 返还和互斥的广告归因优惠；先按平台订单归因检查。
2. 合成订单的已确认合格基数为100，适用比例假设为4%，预计4；若买家含税实付108，也不能直接用108计算。这里的比例只服务算例。
3. 停止参与后旧链接仍可打开，订单没有返还。先检查参与和点击时点；不能因落地正常就报告项目故障，也不能假设重新加入能追溯返还。

## 完成标准

每个金额能回到订单与账上行，每个合格判断有实际依据。无法获得最后触点、活动条款或账单时输出待核清单；不批量发送营销消息，不凭收藏者身份推断营销许可。
