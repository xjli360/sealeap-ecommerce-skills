# Etsy Share & Save 资格与费用对账

## 输入与范围

- 参与状态、条款版本、适用优惠或活动期；若未知不得假设已加入。
- 平台生成的可追踪链接、目标页面、投放渠道与启停日期；分析输出使用匿名链接代号。
- 订单标签、点击/订单统计、Offsite Ads 记录、Payment Account 的费用和返还明细。
- 币种、时区、税费与运费口径、退款或冲销记录，以及外部内容投入成本。

外部引流项目资格和费用返还；与广告投放优化及一般订单利润分析分开。先固定站点与观察日期；事实、估算、假设和未知分开记录。缺决定性资料时完成可确定部分，把其余列为待核或 HOLD。

## 执行流程

1. 读取当前项目说明和账户状态，分开基础规则、限时优惠和未生效设置；把返还定义为卖家费用减免，不能写成买家折扣。
2. 为每个实际外部入口登记平台生成的可追踪链接，检查落地页和商品可售；普通复制链接、站内消息或商品描述不自动视为有效推广入口。
3. 按订单检查参与状态、点击时间、适用窗口、最后点击与 Offsite Ads 冲突。数据缺失时标为资格待核，不把最后点击顺序补成有利假设。
4. 将平台识别的订单、适用费用基数、当期费率或优惠、账上返还和冲销逐行连接；计算预计与已入账差额，避免以店铺总GMV乘固定比例。
5. 把引流访问、符合项目资格的订单、费用节省和内容净贡献分开。归因订单不是已证明的新增订单，点击也不等于成交。
6. 交付异常订单清单及复核材料；需要新增参与、改变链接或接受条款时，按用户现有授权和宿主确认要求处理，并回读结果。

## 交付与验收

- 外部入口与追踪链接登记。
- 订单资格与 Offsite Ads 冲突表。
- 预计返还—账上返还—冲销对账桥。
- 差异原因、未知项和复核步骤。

分支、模板和合成案例见[操作手册](references/playbook.md)；需要核对内容依据与当期规则时读[证据与规则](references/evidence.md)。单个任务只加载所需参考。

## 执行边界

输入、决策流程与案例属于 M（模型综合）；来源不保证经营效果。本 Skill 不表示已连接商户后台。按用户已授权范围执行，已有授权不重复索取；涉及条款或交易的确认按宿主要求处理。提交、处理与实际生效分别验收，工具不可用时交付可审阅方案，不伪造已完成结果。
