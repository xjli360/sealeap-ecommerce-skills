# Etsy 站内广告商品测试

## 任务与输入

店铺日预算、可投商品、曝光点击费用、归因订单、净贡献与产能。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 确认账户实际预算和商品开关，不设计不存在的逐词竞价。
2. 按相近购买任务和利润选小组商品，记录实际而非计划花费。
3. 用曝光→点击→订单→留存贡献观察断点，并检查归因窗口成熟度。
4. 按预先损失上限决定继续、修正或停止，扩大前核产能和库存。

## 判断与交付

交付：测试商品表；预算/损失边界；复盘记录。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
