# 操作手册

以下分支、数据字段和合成案例为M（模型独立综合）；E与R的有限支持范围见 [证据文件](evidence.md)。

## 分支判断

| 观察情况 | 下一步 | 必须避免的误判 |
| --- | --- | --- |
| 主动休店 | 按实际设置恢复并验收 | 暂停新单不暂停旧单责任 |
| 平台强制休店 | 核具体告警与整改条件 | 不能承诺自行切换就恢复 |
| 恢复后短期没有订单 | 排查可购、库存、交期和流量 | 不强制开广告或批量付费续刊 |

## 交付工作表

| 交付项 | 必须保留 |
| --- | --- |
| 休店责任与费用清单 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 恢复前准备表 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 买家端与后台验收 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 恢复观察计划 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |

每个状态都写观察时间；没有发生的动作使用“拟议/待核”，不能写“已完成”。公开报告用匿名代号，原始账户、订单和客户资料留在用户授权范围内。

## 合成案例

### 场景1

输入：人仍在旅途但预计今晚恢复生产。

应有处理：只承诺可兑现的时间，并保留延误缓冲。

### 场景2

输入：休店时自动续刊仍开着。

应有处理：记录可能继续发生的费用，不能称所有收费暂停。

### 场景3

输入：某经营者恢复后很快出单。

应有处理：不写进目标或保证，只记录自己的观察窗口。


## 验收与停止

逐项检查交付是否能追到输入事实。遇到身份不匹配、决定性字段缺失、许可不足或超出用户授权时，停止受影响动作，列明补证与可继续部分。对批量变更保留目标清单、前后值、作用范围和恢复办法；单次请求成功不替代实际结果。
