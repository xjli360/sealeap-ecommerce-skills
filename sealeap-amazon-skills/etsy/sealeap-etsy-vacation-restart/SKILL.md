# Etsy 休店与恢复接单验收

## 输入与范围

- 主动/平台强制休店状态。
- 未完成订单、消息、纠纷与实际制作产能。
- 商品有效期、自动续费、广告与订阅设置。
- 处理时长、公告、自动回复及顾客端展示。

先固定目标市场、观察时间与用户要作的决定。缺少决定性资料时完成可确定部分，把其余标为未知或HOLD，不虚构账户状态。

## 工作流程

1. 先确认休店由谁启用；平台强制状态按通知整改，不把缺少关闭开关当普通界面故障。
2. 暂停前盘点旧订单、消息、纠纷与继续计费项目，明确负责人和可兑现承诺。
3. 恢复前按实际产能设置处理时间，检查商品有效状态、库存、交期和公告，不机械改成教程示例天数。
4. 恢复后核买家可见与可购买，并单独确认广告、自动回复、优惠和续费状态。
5. 用可比窗口观察流量与净订单；如需推广先核预算与同意，不以零单即判算法惩罚。

## 交付

- 休店责任与费用清单。
- 恢复前准备表。
- 买家端与后台验收。
- 恢复观察计划。

分支判断、验收字段和合成案例见 [操作手册](references/playbook.md)；需要查来源范围、计数或当前规则时读 [证据与规则](references/evidence.md)。

## 执行边界

本Skill提供任务流程，不表示已经连接平台或取得商户操作权限。事实、估算、假设、未知分别记录；经验与模型输出不保证收益。只执行用户已授权动作，已有明确授权不重复索取；提交、处理和结果回读分开。网络和工具受限时完成可审阅方案，不绕过访问限制或伪造执行成功。
