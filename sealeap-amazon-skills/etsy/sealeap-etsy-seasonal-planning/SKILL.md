# Etsy 季节选品与交付倒排

## 任务与输入

需求季节、制作产能、打样/物料/运输周期、活动日期和历史订单。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 从顾客需要收到商品的日期倒推最晚制作、确认和发货时间。
2. 区分常青款、季节变体和高不确定新品，确定可承诺产能。
3. 将物料复用、剩货风险和广告试验时间纳入小批计划。
4. 监测订单积压与承诺偏差，必要时收紧可售数量或交付范围。

## 判断与交付

交付：季节倒排表；产能/物料计划；截止与停止条件。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
