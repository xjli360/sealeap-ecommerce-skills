# eBay Priority CPC 与关键词

## 任务与输入

当前可用控制、实际搜索词、CPC/CVR、商品贡献、预算及归因。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 先核Priority计费、站点资格及实际开放的关键词/定向能力。
2. 按意图和商品适配分组，区分品牌、型号、泛词与不相关查询。
3. 用可承受CAC乘CVR情景约束CPC，缺实测时给透明区间。
4. 单变量调整并观察成熟订单贡献，记录库存与自然需求干扰。

## 判断与交付

交付：关键词诊断；CPC区间；预算/损失边界。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
