# 操作手册

以下分支、数据字段和合成案例为M（模型独立综合）；E与R的有限支持范围见 [证据文件](evidence.md)。

## 分支判断

| 观察情况 | 下一步 | 必须避免的误判 |
| --- | --- | --- |
| 修改共享业务政策 | 列出全部关联刊登 | 不能当作只修改选中的一款 |
| 账户排除变更 | 核是否应用于已有刊登 | 未来默认不等于历史全部更新 |
| eIS项目订单已成交 | 核订单项目标识和国内枢纽交接要求 | 不套普通自发货国际流程 |

## 交付工作表

| 交付项 | 必须保留 |
| --- | --- |
| 四层设置与作用域表 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 变更前后及影响清单 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 目的地验收样本 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 未覆盖刊登与恢复记录 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |

每个状态都写观察时间；没有发生的动作使用“拟议/待核”，不能写“已完成”。公开报告用匿名代号，原始账户、订单和客户资料留在用户授权范围内。

## 合成案例

### 场景1

输入：只想限制一件特殊商品。

应有处理：优先最小作用范围，不调整全店所有目的地。

### 场景2

输入：共享政策绑定200条刊登。

应有处理：在变更计划里明确200条影响，不能只展示当前编辑页。

### 场景3

输入：后台保存但旧刊登仍可向目标地购买。

应有处理：判未完成，检查历史应用选项与实际规则。


## 验收与停止

逐项检查交付是否能追到输入事实。遇到身份不匹配、决定性字段缺失、许可不足或超出用户授权时，停止受影响动作，列明补证与可继续部分。对批量变更保留目标清单、前后值、作用范围和恢复办法；单次请求成功不替代实际结果。
