# eBay 国际配送范围与政策变更

## 输入与范围

- 卖家站点、项目参与状态与商品资格。
- 账户排除设置、业务政策及关联刊登清单。
- 目标目的地、需调整商品与既有订单。
- 变更授权、当前前台结果及恢复方案。

先固定目标市场、观察时间与用户要作的决定。缺少决定性资料时完成可确定部分，把其余标为未知或HOLD，不虚构账户状态。

## 工作流程

1. 区分自发货国际选项、eIS参与状态与目的地排除；关闭其中一个不自动代表另两个已关闭。
2. 选择最小必要作用层级：单刊登、批量、共享业务政策或账户；先枚举受影响的当前与未来刊登。
3. 核商品与市场适用条件，保存现有规则和待改名单；不能因个别商品限制就扩成全店排除。
4. 按授权提交后检查处理结果，再按代表目的地和刊登验收实际可购/配送显示。
5. 已成交订单按原订单责任处理；若预期覆盖未生效，保留差异并修正，不反复盲改所有政策。

## 交付

- 四层设置与作用域表。
- 变更前后及影响清单。
- 目的地验收样本。
- 未覆盖刊登与恢复记录。

分支判断、验收字段和合成案例见 [操作手册](references/playbook.md)；需要查来源范围、计数或当前规则时读 [证据与规则](references/evidence.md)。

## 执行边界

本Skill提供任务流程，不表示已经连接平台或取得商户操作权限。事实、估算、假设、未知分别记录；经验与模型输出不保证收益。只执行用户已授权动作，已有明确授权不重复索取；提交、处理和结果回读分开。网络和工具受限时完成可审阅方案，不绕过访问限制或伪造执行成功。
