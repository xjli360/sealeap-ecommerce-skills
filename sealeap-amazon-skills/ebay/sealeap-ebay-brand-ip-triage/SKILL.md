# eBay 品牌与 VeRO 证据初筛

## 任务与输入

权利类型/地域、权利人授权、涉事内容、原始作品与事实证据。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 先核申诉方权利与授权，区分商标、版权、专利和普通分销纠纷。
2. 逐项对照疑似内容与权利范围，不以低价或未授权经销直接认定侵权。
3. 整理可复核证据和不确定点，争议法律判断交专业处理。
4. 仅在明确授权及证据足够时准备提交材料，未提交与已受理分开记录。

## 判断与交付

交付：权利与证据矩阵；待核问题；投诉草稿。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
