# 操作手册

以下分支、数据字段和合成案例为M（模型独立综合）；E与R的有限支持范围见 [证据文件](evidence.md)。

## 分支判断

| 观察情况 | 下一步 | 必须避免的误判 |
| --- | --- | --- |
| 同一刊登买两件 | 验证追加件设置 | 不拿跨刊登规则替代 |
| 两个不同刊登 | 验证合并规则与业务政策关联 | 不能仅看已建立规则名称 |
| 已付款且允许处理差额 | 形成可审阅退款金额与依据 | 不重新收一次合并发票 |

## 交付工作表

| 交付项 | 必须保留 |
| --- | --- |
| 购物篮测试矩阵 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 规则-政策-刊登映射 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 实收/实付运费桥接 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 发票或差额处理草稿 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |

每个状态都写观察时间；没有发生的动作使用“拟议/待核”，不能写“已完成”。公开报告用匿名代号，原始账户、订单和客户资料留在用户授权范围内。

## 合成案例

### 场景1

输入：合成：单品首件费8、同款追加2。

应有处理：先测试同款两件；不能据此推断不同刊登也只加2。

### 场景2

输入：两个轻件合箱后体积跨收费档。

应有处理：重新比承运报价和贡献，不承诺固定节省。

### 场景3

输入：涉及不同买家或不同地址。

应有处理：不能为节约运费合并成同一包裹。


## 验收与停止

逐项检查交付是否能追到输入事实。遇到身份不匹配、决定性字段缺失、许可不足或超出用户授权时，停止受影响动作，列明补证与可继续部分。对批量变更保留目标清单、前后值、作用范围和恢复办法；单次请求成功不替代实际结果。
