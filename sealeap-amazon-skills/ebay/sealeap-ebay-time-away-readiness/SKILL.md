# eBay Time Away 与休假履约准备

## 输入与范围

- 站点、计划离开/返回时间及当地时区，能否由他人发货或处理售后。
- 有效固定价刊登、拍卖及结束时间、待处理报价、取货/数字商品等特殊订单范围。
- 已有未发货订单、承诺交期、退货/纠纷与待回复消息；仅使用必要匿名标识。
- 当前 Time Away 和自动回复设置、剩余履约产能、假期期间持续费用。

eBay 休假模式与订单覆盖；与跨境配送配置和其他平台休店机制分开。先固定站点与观察日期；事实、估算、假设和未知分开记录。缺决定性资料时完成可确定部分，把其余列为待核或 HOLD。

## 执行流程

1. 确定可履约的最早日期、每日产能和售后值守，先列已有订单；休假设置不能把原有承诺自动推迟。
2. 按当前规则比较 Allow sales 与 Pause sales，逐类标出固定价、拍卖及例外。选择暂停不等于所有商品都停止成交。
3. 检查尚未接受的报价、当地取货、数字类目等不随通常交期调整的场景；存在无人覆盖的责任则提出处理方案，不能宣告可离线休假。
4. 将销售设置的开始/结束与消息自动回复分开配置和核验，回复内容只说明真实处理时间，不承诺无法保证的日期。
5. 若获授权执行，保存后回读设置，再在买家端抽查固定价可见性和交期；记录仍在传播或未更新的状态。
6. 返回前核对积压订单、实际产能、剩余例外、恢复设置与自动回复关闭；保留逐日清单而不是只看恢复开关。

## 交付与验收

- 固定价、拍卖与特殊交易覆盖表。
- 既有订单及售后值守安排。
- Time Away 与自动回复设置验收。
- 复工积压与恢复接单检查表。

分支、模板和合成案例见[操作手册](references/playbook.md)；需要核对内容依据与当期规则时读[证据与规则](references/evidence.md)。单个任务只加载所需参考。

## 执行边界

输入、决策流程与案例属于 M（模型综合）；来源不保证经营效果。本 Skill 不表示已连接商户后台。按用户已授权范围执行，已有授权不重复索取；涉及条款或交易的确认按宿主要求处理。提交、处理与实际生效分别验收，工具不可用时交付可审阅方案，不伪造已完成结果。
