# eBay 单件库存与多渠道同步

## 任务与输入

实物ID、各渠道刊登、可售/锁定、待付款/取消、同步延迟。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 建立实物到刊登映射，区分单件唯一商品与同质多件库存。
2. 明确可售来源和订单锁定/释放条件，记录事件时间与幂等键。
3. 分析同步延迟和并发订单下的超卖窗口，提出保守缓冲或下架规则。
4. 用合成事件回放验证库存变化，实际修改后读回所有目标渠道。

## 判断与交付

交付：库存身份表；同步状态机；超卖测试清单。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
