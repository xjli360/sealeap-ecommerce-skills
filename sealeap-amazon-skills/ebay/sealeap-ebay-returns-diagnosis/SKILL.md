# eBay 退货与描述不符诊断

## 任务与输入

匿名订单、买家原因、原刊登、实物测试、追踪、退款与回收。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 区分描述不符、运输损坏、兼容误选和改变主意，核事实而非只信标签。
2. 按商品/批次/成色/线路比较发生率与金额，去重同一售后。
3. 计算退款后收入、不可退费用、退运与回收价值。
4. 将根因回填照片、兼容表、包材或检测，并准备回复草稿。

## 判断与交付

交付：退货根因表；贡献损失；改进与沟通草稿。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
