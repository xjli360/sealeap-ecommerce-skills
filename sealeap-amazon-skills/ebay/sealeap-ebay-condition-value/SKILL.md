# eBay 成色分层与整备价值

## 任务与输入

测试结果、缺陷、配件、可比已售、整备工时/零件和售后。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 按可验证功能、外观、配件与包装分层，保留故障和未测状态。
2. 同层比较成交总价，核照片和描述是否足以让买家识别差异。
3. 估算整备成本、成功率情景、售后损失与时间占用。
4. 比较原状出售、修复后出售和放弃采购，缺测试证据先HOLD。

## 判断与交付

交付：成色证据表；整备收益情景；采购判断。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
