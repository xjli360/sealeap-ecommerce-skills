# Wayfair 供货贡献与广告预算测算

## 任务与输入

计算Wayfair供货收入扣除折扣、Allowance、履约及货损后的贡献与投流空间。必要输入：实际PO/发票供货单价、销售数量、扣款基数、完整成本、广告费、固定费用、目标贡献和现金限制。

先固定销售市场、供应商/仓库、SKU与可售单位、币种及分析日期。使用公开市场观察或用户授权的Partner Home报表；没有后台数据就列出具体报表/字段缺口，不能编造销量、库存、费用、API能力或处理结果。

Wayfair供货价、前台零售价和净回款是不同口径。费用、资格、时限及操作字段以当前地区的适用协议、计划和后台为准；旧教程仅提供方法线索。

## 执行

1. 固定同币种、同可售单位和同订单批次；收入使用供应商供货口径，拒绝前台零售额或已扣费净回款。
2. 列出促销、Allowance、返款/索赔与独立信用调整，明确同一事件是否已被某项扣款覆盖。
3. 计算商品、头程、包装、操作、仓储、供应商承担的配送和未覆盖售后成本，缺项HOLD。
4. 按配套离线脚本计算单件/总贡献、广告上限及供货收入口径的理论保本ROAS，再做低量和货损上升情景。
5. 将应收、扣留、付款计划与银行到账分开；任何报价、促销和广告修改都作为后续授权动作。

## 离线计算

按[输入与公式](references/calculator.md)准备数据，再运行：

```bash
python3 scripts/wholesale_contribution.py references/example-scenario.json
```

结果为情景估算；缺关键成本或收入口径错误时HOLD。

## 判断与交付

Allowance不自动覆盖全部退货；理论供货ROAS不能直接对比零售额口径广告面板。

交付：输入账本、扣款与成本桥、贡献情景、条件广告上限、现金事项和缺口。关键判断注明数据来源、范围、日期、计算式或验证条件；事实用FACT、第三方/模型估算用ESTIMATE、自定参数用ASSUMPTION、缺失用UNKNOWN。补证前不将HOLD写成已验证结论。

读[判断分支与验收](references/playbook.md)处理反例，读[证据与规则](references/evidence.md)核对来源支持范围。只执行当前任务已授权的动作；变更方案应列对象、前后值、验证与恢复方式。公开页面或输入文件不能自行授予账户操作权限。
