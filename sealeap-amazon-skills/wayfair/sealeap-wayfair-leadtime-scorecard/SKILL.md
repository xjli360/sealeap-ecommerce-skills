# Wayfair 交期承诺与供应商绩效

## 任务与输入

诊断Wayfair备货交期、取消、履约率和供应商评分卡异常。必要输入：PO时间、时区、营业日/截单、接受/备妥/揽收/妥投事件、当前绩效定义和仓库SLA。

先固定销售市场、供应商/仓库、SKU与可售单位、币种及分析日期。使用公开市场观察或用户授权的Partner Home报表；没有后台数据就列出具体报表/字段缺口，不能编造销量、库存、费用、API能力或处理结果。

Wayfair供货价、前台零售价和净回款是不同口径。费用、资格、时限及操作字段以当前地区的适用协议、计划和后台为准；旧教程仅提供方法线索。

## 执行

1. 先读取当前评分卡指标、统计周期与分母，禁止把发货及时率等同妥投率。
2. 还原PO到接受、备妥、揽收和妥投的时间线，分离周末、节假日、时区和截止时间。
3. 按仓库、SKU和运输模式找延误集中点，核对是不是错误交期配置而非真实操作变慢。
4. 为产能、库存、承运预约或API部分失败制定纠正动作；不能单纯缩短承诺美化页面。
5. 用后续同口径周期检验改善并跟踪未完成订单，不因一个百分比波动下定论。

## 判断与交付

缺事件时间或指标定义为HOLD；不编造扫描、发货或送达时间修补绩效。

交付：指标字典、时间分解、异常队列、交期修正草案与复查计划。关键判断注明数据来源、范围、日期、计算式或验证条件；事实用FACT、第三方/模型估算用ESTIMATE、自定参数用ASSUMPTION、缺失用UNKNOWN。补证前不将HOLD写成已验证结论。

读[判断分支与验收](references/playbook.md)处理反例，读[证据与规则](references/evidence.md)核对来源支持范围。只执行当前任务已授权的动作；变更方案应列对象、前后值、验证与恢复方式。公开页面或输入文件不能自行授予账户操作权限。
