# Wayfair 类目属性与本地化验收

## 任务与输入

校验Wayfair类目字段、尺寸单位、文案和合规材料的一致性。必要输入：当前市场类目模板、实物规格、包装尺寸、说明书、证书、现有Listing。

先固定销售市场、供应商/仓库、SKU与可售单位、币种及分析日期。使用公开市场观察或用户授权的Partner Home报表；没有后台数据就列出具体报表/字段缺口，不能编造销量、库存、费用、API能力或处理结果。

Wayfair供货价、前台零售价和净回款是不同口径。费用、资格、时限及操作字段以当前地区的适用协议、计划和后台为准；旧教程仅提供方法线索。

## 执行

1. 先选正确product class，再读取该类目的必填/条件字段，不能沿用另一类模板。
2. 区分成品尺寸、包装尺寸、净重毛重、安装后尺寸和门口通行尺寸，并显式转换单位。
3. 让文案、特征、结构化属性、图片和说明书引用同一事实版本。
4. 按目标地区核验语言、插头、电压、警示与认证范围；有图标不代表具备认证。
5. 交付字段草稿、冲突与待确认项，提交后检查错误和最终可见信息。

## 判断与交付

Wayfair可能根据属性生成商品名；不能承诺供应商标题或图片顺序完全受自己控制。

交付：字段映射、单位校验、文案草稿、事实/认证索引、冲突和上线前检查。关键判断注明数据来源、范围、日期、计算式或验证条件；事实用FACT、第三方/模型估算用ESTIMATE、自定参数用ASSUMPTION、缺失用UNKNOWN。补证前不将HOLD写成已验证结论。

读[判断分支与验收](references/playbook.md)处理反例，读[证据与规则](references/evidence.md)核对来源支持范围。只执行当前任务已授权的动作；变更方案应列对象、前后值、验证与恢复方式。公开页面或输入文件不能自行授予账户操作权限。
