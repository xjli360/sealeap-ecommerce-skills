# 判读手册

本页是针对本任务独立整理的M执行设计；来源只支持[证据文件](evidence.md)注明的范围。

## 决策边界

- AOV提高不等于利润提高；LTV以成熟队列贡献定义。
- 不预设订阅适合所有耐用品，不通过隐藏取消条件降低流失。

## 输入缺口怎样影响结论

本任务需要：订单篮子、商品兼容、队列复购、优惠成本、库存与贡献。

把缺口关联到具体判断：缺真实费用则不给精确利润；缺事件数量则不推转化；缺权限或平台能力则不宣称能执行。已有数据足以完成某部分时继续，不为等一项资料阻断全部工作。以观察性证据提出的原因写为“待验证假设”。

## 可交付模板

| 交付项 | 填写内容 |
| --- | --- |
| 组合候选表 | 对应对象与范围、具体结果、依据/口径、未知项及下一步 |
| 优惠情景 | 对应对象与范围、具体结果、依据/口径、未知项及下一步 |
| 队列复盘 | 对应对象与范围、具体结果、依据/口径、未知项及下一步 |

保留与结论相关的明细及观察日期；对外输出用匿名对象代号。收费、资格、时限和控制项以实际市场当期规则为准，不能填固定行业常数代替账户事实。

## 易错场景（合成）

两件套AOV提升但运费跨档且替代高毛利单品，贡献可能下降，应重新定价或拆组合。

## 完成标准

流程中的每个主要判断都能落到上述交付项，未通过的条件有明确补证或停止动作。需要变更时提供目标、前后值、作用范围、验证和恢复办法；纯分析任务到此交付，不暗中扩成账户操作。

## 组合收益与履约资格分开核验

组合经济性通过后，仍需检查每套组件用量、库存估算排除项、目标渠道与购买选项兼容、拆分履约和部分退货。组件已发布或组合价格有利润，都不能证明组合已可购买和交付。

这是M执行补充；新证据及官方规则见证据文件。
