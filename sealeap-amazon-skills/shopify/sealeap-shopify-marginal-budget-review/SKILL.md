# Shopify 边际收益与预算方案评审

## 输入与范围

- 已验证模型版本、目标变量、窗口及外样本结果。
- 渠道响应曲线/情景、当前支出、历史可观察区间。
- 总预算、渠道上下限、合同/库存/现金约束。
- 商品贡献结构、实验校准证据与不确定性。

先固定目标市场、观察时间与用户要作的决定。缺少决定性资料时完成可确定部分，把其余标为未知或HOLD，不虚构账户状态。

## 工作流程

1. 核模型目标与经营目标是否一致，区分固定预算最大响应和目标效率两种问题。
2. 查看平均ROAS与边际响应的不同，核衰减、饱和及支出到曝光映射的假设。
3. 约束每个渠道的上下限、预算总量与实际可交付能力，对外推区间和零数据渠道标记HOLD。
4. 比较基线与候选在多个合理模型/情景下的净贡献，记录结论对假设的敏感性。
5. 把模型建议转换成小范围预算实验与回退条件；未有用户实际投放授权时不写账户。

## 交付

- 预算约束表。
- 基线与候选情景。
- 边际响应/不确定性说明。
- 有限实验与回退清单。

分支判断、验收字段和合成案例见 [操作手册](references/playbook.md)；需要查来源范围、计数或当前规则时读 [证据与规则](references/evidence.md)。

## 执行边界

本Skill提供任务流程，不表示已经连接平台或取得商户操作权限。事实、估算、假设、未知分别记录；经验与模型输出不保证收益。只执行用户已授权动作，已有明确授权不重复索取；提交、处理和结果回读分开。网络和工具受限时完成可审阅方案，不绕过访问限制或伪造执行成功。
