# 操作手册

以下分支、数据字段和合成案例为M（模型独立综合）；E与R的有限支持范围见 [证据文件](evidence.md)。

## 分支判断

| 观察情况 | 下一步 | 必须避免的误判 |
| --- | --- | --- |
| 平均ROAS高但边际收益低 | 看新增一单位支出的预测变化 | 不能仅按历史平均ROAS排序预算 |
| 建议远超历史投放范围 | 标外推风险并缩成可验证实验 | 优化器输出不是效果保证 |
| 模型收入增加但贡献下降 | 加入毛利、优惠、履约和库存限制 | 不把收入最大当利润最大 |

## 交付工作表

| 交付项 | 必须保留 |
| --- | --- |
| 预算约束表 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 基线与候选情景 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 边际响应/不确定性说明 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 有限实验与回退清单 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |

每个状态都写观察时间；没有发生的动作使用“拟议/待核”，不能写“已完成”。公开报告用匿名代号，原始账户、订单和客户资料留在用户授权范围内。

## 合成案例

### 场景1

输入：合成：渠道A平均ROAS高，但增加预算的预测贡献低于B。

应有处理：在曲线和约束有效前提下比较边际情景，不能直接把全部钱转走。

### 场景2

输入：新渠道没有历史数据，优化器分配大额预算。

应有处理：标未知并设计探索预算，不伪造曲线。

### 场景3

输入：最优方案会让畅销SKU断货。

应有处理：加入供给约束后重评，而非直接执行。


## 验收与停止

逐项检查交付是否能追到输入事实。遇到身份不匹配、决定性字段缺失、许可不足或超出用户授权时，停止受影响动作，列明补证与可继续部分。对批量变更保留目标清单、前后值、作用范围和恢复办法；单次请求成功不替代实际结果。
