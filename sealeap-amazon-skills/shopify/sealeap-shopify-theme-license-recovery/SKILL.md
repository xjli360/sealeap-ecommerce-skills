# Shopify 主题许可与恢复准备

## 输入与范围

- 主题来源、主题ID、适用许可条款和购买记录。
- 许可对应商店、转移条件及告警原文。
- 已发布与草稿副本清单、配置备份和替代方案。
- 用户授权动作、通知期限与真实前台状态。

先固定目标市场、观察时间与用户要作的决定。缺少决定性资料时完成可确定部分，把其余标为未知或HOLD，不虚构账户状态。

## 工作流程

1. 区分Theme Store付费主题、免费主题和其他合法第三方主题，不因上传ZIP就认定盗版。
2. 把告警主题与商店及购买证据对应，核是否有改名副本、跨店复制或缺许可资料。
3. 形成补证、合法购买、符合条件的转移或移除方案，标明各自影响及不可逆步骤。
4. 切换主题与移除有问题副本分别验收；不因换到免费主题就宣称许可问题解决。
5. 按实际授权处理并回读后台告警和前台访问；恢复未发生时保留待核，不承诺自动或立即解封。

## 交付

- 主题-许可-商店对照。
- 告警与证据缺口。
- 可审阅恢复方案。
- 后台和前台验收记录。

分支判断、验收字段和合成案例见 [操作手册](references/playbook.md)；需要查来源范围、计数或当前规则时读 [证据与规则](references/evidence.md)。

## 执行边界

本Skill提供任务流程，不表示已经连接平台或取得商户操作权限。事实、估算、假设、未知分别记录；经验与模型输出不保证收益。只执行用户已授权动作，已有明确授权不重复索取；提交、处理和结果回读分开。网络和工具受限时完成可审阅方案，不绕过访问限制或伪造执行成功。
