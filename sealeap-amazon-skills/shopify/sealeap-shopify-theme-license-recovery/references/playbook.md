# 操作手册

以下分支、数据字段和合成案例为M（模型独立综合）；E与R的有限支持范围见 [证据文件](evidence.md)。

## 分支判断

| 观察情况 | 下一步 | 必须避免的误判 |
| --- | --- | --- |
| 许可文件存在 | 核许可究竟适用哪个商店与用途 | 文件存在不等于覆盖多店 |
| 来源为第三方设计者 | 读其真实条款和官方支持渠道 | 不能把非Theme Store主题一概判无授权 |
| 转移要求关闭旧店 | 列为独立的不可逆决策 | 本Skill不自行关店或购买 |

## 交付工作表

| 交付项 | 必须保留 |
| --- | --- |
| 主题-许可-商店对照 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 告警与证据缺口 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 可审阅恢复方案 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 后台和前台验收记录 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |

每个状态都写观察时间；没有发生的动作使用“拟议/待核”，不能写“已完成”。公开报告用匿名代号，原始账户、订单和客户资料留在用户授权范围内。

## 合成案例

### 场景1

输入：发布免费主题后原付费草稿还在。

应有处理：继续核告警对应副本，不声称完成。

### 场景2

输入：两家店使用同一Theme Store发票。

应有处理：按每店许可及当期转移条件核验，不能改主题名解决。

### 场景3

输入：有合法外部设计授权。

应有处理：保留条款与授权范围，走澄清路径，不直接删除。


## 验收与停止

逐项检查交付是否能追到输入事实。遇到身份不匹配、决定性字段缺失、许可不足或超出用户授权时，停止受影响动作，列明补证与可继续部分。对批量变更保留目标清单、前后值、作用范围和恢复办法；单次请求成功不替代实际结果。
