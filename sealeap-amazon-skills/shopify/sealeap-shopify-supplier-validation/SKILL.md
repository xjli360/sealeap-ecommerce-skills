# Shopify 供应商与样品验证

## 任务与输入

规格清单、报价/MOQ、样品、包装、目的国交期、追踪与退货责任。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 先冻结规格和验收条件，再比较同包装、运输与贸易条件的报价。
2. 以样品检查关键尺寸、功能、材料证据、包装与误用风险，记录不通过项。
3. 按订单波动、缺货率、追踪回传与售后责任比较代发和备货。
4. 制定小批交付试验、付款节点与退出条件，不把采购建议写成已下单。

## 判断与交付

交付：供应比较表；样品验收单；小批验证计划。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
