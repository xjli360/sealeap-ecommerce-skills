# Shopify AI销售渠道可售与数据验收

## 输入与范围

固定商店、目标国家/币种、AI渠道、计划类型、观察时间及授权范围。收集后台Agentic与Catalog状态、商品/变体事实、数据映射、其他Feed、B2B目录及购买路径证据。没有后台访问时交付公开观察和待补字段，不猜账户资格。

## 工作流程

1. 分开确认商店Catalog资格、商品资格、渠道是否启用、目标市场及购买方式。平台默认启用或公告开放不证明当前账户每个渠道均可直接结账。
2. 按来源核商品标题、规格、变体、图片、币种价格与库存；自定义字段或分组逻辑先检查Catalog Mapping，不只改网页可见标题。
3. 用正常商品、多变体商品和应排除商品建立样本。记录可被发现、被展示、可购买及已成交四种状态；每条结论保留渠道与时间。
4. 检查跳转结账或直接结账的地区、配送、退款说明和订单来源；仅在明确允许的测试范围内操作，真实下单另须任务授权。
5. 检查原生B2B目录、公司/地点或登录限制及第三方批发逻辑。AI渠道的D2C价格与B2B条件分开；自定义隐藏价格不保证排除。
6. 对误显示、旧价格、变体错配或不可购给出对象级修复草稿，明确数据源、前后值和回读/恢复办法。没有授权不切换渠道、不发布商品。

## 交付与判定

交付渠道资格矩阵、商品字段映射、购买路径结果、B2B排除清单和修复优先级。关键资格或身份未知时标为待核；通过只表示指定样本在指定时间的验收结果，不保证后续曝光、排名、增量或所有商品覆盖。

遇到抓取、分发、批发或购买路径混淆时读[判读与合成案例](references/playbook.md)；核对平台规则及实际读取范围时读[官方依据](references/evidence.md)。本包可独立复制，不要求安装专用付费工具。
