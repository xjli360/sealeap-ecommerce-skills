# Shopify 营销组合建模数据准备

## 输入与范围

- 明确的业务问题、KPI和决策粒度。
- 同频率收入/销量与退款数据、真实媒体支出和曝光。
- 价格、促销、缺货、渠道变化、节日与经营事件。
- 数据起止、币种、时区、来源、缺失与变更日志。

先固定目标市场、观察时间与用户要作的决定。缺少决定性资料时完成可确定部分，把其余标为未知或HOLD，不虚构账户状态。

## 工作流程

1. 先确定要回答的预算问题及KPI，拆开平台归因收入与实际经营总额。
2. 按同一周起始日/时间粒度对齐数据，区分真实零值、缺失、延迟与计划数，抽样对账后再扩全集。
3. 检查渠道变化量、有效样本、共线性、促销与缺货的重叠；不能靠机械拆成更多变量提高可信度。
4. 建立按时间顺序的训练、验证与外样本评估方案，保留价格/媒体定义变化等结构断点。
5. 交付GO/HOLD数据准备结论和需要额外实验的识别缺口；拟合模型、实验校准和预算上线是后续独立任务。

## 交付

- 变量与来源字典。
- 时间序列质量表。
- 可识别性与混杂清单。
- 建模准备判定及补证任务。

分支判断、验收字段和合成案例见 [操作手册](references/playbook.md)；需要查来源范围、计数或当前规则时读 [证据与规则](references/evidence.md)。

## 执行边界

本Skill提供任务流程，不表示已经连接平台或取得商户操作权限。事实、估算、假设、未知分别记录；经验与模型输出不保证收益。只执行用户已授权动作，已有明确授权不重复索取；提交、处理和结果回读分开。网络和工具受限时完成可审阅方案，不绕过访问限制或伪造执行成功。
