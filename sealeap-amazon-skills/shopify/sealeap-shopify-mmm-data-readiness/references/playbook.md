# 操作手册

以下分支、数据字段和合成案例为M（模型独立综合）；E与R的有限支持范围见 [证据文件](evidence.md)。

## 分支判断

| 观察情况 | 下一步 | 必须避免的误判 |
| --- | --- | --- |
| 媒体费用几乎同步变化 | 提示难以分辨独立效果，考虑可解释聚合或补实验 | 高相关模型不是因果证明 |
| 新店短期数据不足 | 提出有界实验或延长观察 | 不能套一个固定周数就保证识别 |
| 指标定义中途改变 | 分段记录并评估是否可比 | 不要将追踪修复当真实销售增长 |

## 交付工作表

| 交付项 | 必须保留 |
| --- | --- |
| 变量与来源字典 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 时间序列质量表 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 可识别性与混杂清单 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |
| 建模准备判定及补证任务 | 对象与版本、事实/口径、结论、未知项、负责人和下一次验收 |

每个状态都写观察时间；没有发生的动作使用“拟议/待核”，不能写“已完成”。公开报告用匿名代号，原始账户、订单和客户资料留在用户授权范围内。

## 合成案例

### 场景1

输入：所有广告渠道在旺季同周翻倍。

应有处理：标媒体与季节难分，不直接给各渠道增量ROI。

### 场景2

输入：报表漏了两周费用。

应有处理：保留缺失并补数据，不能填零。

### 场景3

输入：模型要解释净收入却输入未扣退货GMV。

应有处理：统一目标口径后再建模。


## 验收与停止

逐项检查交付是否能追到输入事实。遇到身份不匹配、决定性字段缺失、许可不足或超出用户授权时，停止受影响动作，列明补证与可继续部分。对批量变更保留目标清单、前后值、作用范围和恢复办法；单次请求成功不替代实际结果。
