# Shopify 履约与退货成本诊断

## 任务与输入

匿名订单、承诺/实发/签收、承运账单、退货状态、回收价值。先固定站点、时间范围、币种、商品身份和用户目标。缺少决定性数据时先完成可确定部分，把未知列成验证任务。

## 执行流程

1. 将履约阶段拆为备货、发货、运输、签收与退货处理，统一时区。
2. 按SKU、仓库、承运线路和原因看异常，避免重复计同一售后事件。
3. 核算补寄、退款、不可退费用、回收与再上架成本。
4. 优先修复根因并比较物流方案，拟服务承诺与验证窗口。

## 判断与交付

交付：履约异常矩阵；退货贡献桥接；修复计划。每项判断附事实依据、数据口径、未确定事项和下一步；估算、假设与事实分别标注。

涉及分支判断、边界和交付模板时读 [判读手册](references/playbook.md)；核查资料范围与平台规则时读 [证据与规则](references/evidence.md)。只读取本次任务需要的参考。

## 执行范围

经营步骤和案例为M（模型综合），不是来源的实测收益或平台保证。工具不可用时交付方案和数据需求，不伪造后台结果。仅执行用户已授权动作；投放、采购、发布、寄样及联系他人须在实际授权范围内，已有授权不重复索取。执行后核对实际状态，不把提交成功当结果已生效。
