# 美客多知识产权与刊登限制初筛

## 任务与输入

- 当前站点、原始平台通知、受影响刊登、期限与允许的回应动作。
- 真实商品、品牌/素材来源、采购或授权文件和已有更正。
- 举报针对的具体权利或规则，以及能合法提供的证据。

先固定国家站、经营/物流模式、币种和观察日期。将事实、估算、假设与未知分开；缺关键资料时完成可确定部分，把受影响的判断留待补证。

## 工作流程

1. 区分平台类目限制、知识产权报告、共享目录错误和一般商业争议，不根据‘被下架’直接推断侵权成立。
2. 核商品真实性、品牌/素材使用依据及目录一致性；未查到注册、供应商口头保证或他人也在卖均不是授权。
3. 将每项主张与证据配对，指出缺口；价格竞争或渠道分歧不能伪装成知识产权举报。
4. 准备真实、最小必要的回应或整改草稿，记录当前期限和实际状态；重大或无法判断的权利问题交由专业人士确认。

## 交付

交付问题类型、证据矩阵、整改或回应草稿与需要专业确认的事项。

遇到条件分支、字段设计和误判场景时读[操作手册](references/playbook.md)；核查来源实际支持范围和当期规则时读[证据与规则](references/evidence.md)。

## 执行范围

本包的流程、模板和算例为 M（模型综合），不表示已接入美客多或验证经营收益。只执行用户已授权的动作，已有授权不重复索取；变更需明确对象、前后值、实际能力与回读办法。工具不可用时交付方案和输入需求，不伪造已生效结果。
