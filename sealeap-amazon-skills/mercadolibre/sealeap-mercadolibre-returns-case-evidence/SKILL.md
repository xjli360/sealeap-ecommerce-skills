# 美客多退货案件与证据处理

## 任务与输入

- 订单、claim、return及包裹之间的关联，站点和经营/物流模式。
- 退货物流、资金、仓库检验、卖家可执行动作和当前截止时间。
- 真实出库、包装、配件、序列或规格证据及实际退回检查记录。

先固定国家站、经营/物流模式、币种和观察日期。将事实、估算、假设与未知分开；缺关键资料时完成可确定部分，把受影响的判断留待补证。

## 工作流程

1. 建立订单—案件—退货—物流—资金关系，区分普通退货、争议和平台仓库已检验的情况。
2. 读取当前责任方、可执行动作与期限；缺API能力的角色使用已授权后台材料，不能用别的账户代办。
3. 按未收到、损坏、缺配件、错品或符合预期分类，记录事实与不确定处；不要仅凭一张图指控欺诈。
4. 比较平台允许的处理选项并准备证据，尊重买家权利；获授权执行后追踪裁定、退款及库存去向分别生效。

## 交付

交付案件状态图、事实证据包、处理方案或复核草稿，以及后续对账任务。

遇到条件分支、字段设计和误判场景时读[操作手册](references/playbook.md)；核查来源实际支持范围和当期规则时读[证据与规则](references/evidence.md)。

## 执行范围

本包的流程、模板和算例为 M（模型综合），不表示已接入美客多或验证经营收益。只执行用户已授权的动作，已有授权不重复索取；变更需明确对象、前后值、实际能力与回读办法。工具不可用时交付方案和输入需求，不伪造已生效结果。
