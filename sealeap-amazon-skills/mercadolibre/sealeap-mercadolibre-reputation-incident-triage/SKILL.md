# 美客多信誉指标与异常处理

## 任务与输入

- 站点、物流/经营模式、显示信誉与保护期信息。
- 指标周期、分母、违规/排除明细、关联订单和真实处理时间。
- 商品质量、库存、履约和客服过程证据。

先固定国家站、经营/物流模式、币种和观察日期。将事实、估算、假设与未知分开；缺关键资料时完成可确定部分，把受影响的判断留待补证。

## 工作流程

1. 固定当前指标窗口和口径，将显示颜色、真实指标及保护状态分开，不混算不同站点或周期。
2. 把取消、延迟、投诉等异常连接到订单，排除重复案件和已排除记录后核对应分母。
3. 先处理客户实际问题与根因，再判断是否符合官方排除或复核条件；不把关闭投诉当唯一目标。
4. 交付修复优先级、补证清单和观察计划；效果需按平台更新周期回读，不保证某日期恢复颜色。

## 交付

交付可复核的信誉诊断、根因行动和符合条件的复核材料。

遇到条件分支、字段设计和误判场景时读[操作手册](references/playbook.md)；核查来源实际支持范围和当期规则时读[证据与规则](references/evidence.md)。

## 执行范围

本包的流程、模板和算例为 M（模型综合），不表示已接入美客多或验证经营收益。只执行用户已授权的动作，已有授权不重复索取；变更需明确对象、前后值、实际能力与回读办法。工具不可用时交付方案和输入需求，不伪造已生效结果。
