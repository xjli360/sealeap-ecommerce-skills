# 离线测算输入与边界

从本Skill目录运行：

```bash
python3 scripts/unit_economics.py references/scenario.example.json
```

示例为合成数据，不是美客多费率或税务建议。脚本只读取本地JSON，不访问网络或账户。

## 口径合同

- 所有金额必须同币种；`unit_revenue`是每个销售单元扣卖家优惠、排除不属于收入的代收税后，尚未扣平台费用的收入。
- `revenue_basis`必须为`seller_sales_before_platform_deductions`。如果手里只有已经扣费的net proceeds，先按账单还原或另做账桥，不能直接放入并再次扣费。
- `units`是该销售单元的非负整数数量。不同变体、售价或成本不同，分别运行情景。
- `unit_costs`八项都要填写：采购、入仓/头程、平台费、配送、不可回收税、仓储、预期退货损失和其他可变成本。未知项填null会得到HOLD；明确不适用才填0。
- `ad_spend`为情景总广告费；`recoverable_withholding_cash`和`held_cash`为情景总现金限制，不是单件值。
- 只有已确认可抵扣/可回收的代扣款才填入`recoverable_withholding_cash`；不确定其性质时先补证，不能为了提高利润把税费移出成本。
- `basis_note`注明金额依据、日期及假设。平台、物流及税费报价由用户或当前合法数据源提供，脚本不内置任何国家费率。

## 计算含义

单位广告前贡献 = 单位收入 − 单位可变成本。总广告后贡献再扣总广告费。理论盈亏平衡ROAS为单位收入除以正的单位广告前贡献；贡献非正时返回null。

现金字段进一步扣除确认可回收的代扣和暂扣，只表达这个简化情景的现金压力；不是银行可用余额，也不代表付款/回款时点已验证。固定费用和融资成本另列。

样例应得到：总收入1000，广告前贡献400，广告后贡献300，现金情景210，理论盈亏平衡ROAS 2.50。实际指标分母或归因商品不同，不能拿这个数直接设广告目标。
