# 美客多单位经济与现金测算

## 任务与输入

- 站点、币种、SKU、单位售价及其含税/优惠口径，订单或预测数量。
- 采购、头程、平台费、尾程、不可回收税费、仓储、退货损失和其他可变成本。
- 广告支出、可抵扣代扣税、暂扣资金及凭据；未知不能填零。

先固定国家站、经营/物流模式、币种和观察日期。将事实、估算、假设与未知分开；缺关键资料时完成可确定部分，把受影响的判断留待补证。

## 工作流程

1. 统一金额口径，区分买家付款、卖家收入、平台净回款、可变成本及可抵扣税款。
2. 从实际账单或已填写条件的官方计算器取费用；空计算器的0值、旧视频费率和其他站点报价不可作依据。
3. 计算广告前/后贡献与回款现金压力；对退货、仓龄、运费和售价做情景，固定费用另列。
4. 给出理论盈亏平衡广告回报与目标缺口，注明它不是实际ROAS保证；需要重复计算时使用本包离线脚本。

## 交付

重复计算时先读[离线测算合同](references/calculator-contract.md)，再运行本包的 `scripts/unit_economics.py`；不要把默认值当平台报价。

交付同币种的贡献与现金情景、可承受广告支出、缺失成本和计算依据。

遇到条件分支、字段设计和误判场景时读[操作手册](references/playbook.md)；核查来源实际支持范围和当期规则时读[证据与规则](references/evidence.md)。

## 执行范围

本包的流程、模板和算例为 M（模型综合），不表示已接入美客多或验证经营收益。只执行用户已授权的动作，已有授权不重复索取；变更需明确对象、前后值、实际能力与回读办法。工具不可用时交付方案和输入需求，不伪造已生效结果。
