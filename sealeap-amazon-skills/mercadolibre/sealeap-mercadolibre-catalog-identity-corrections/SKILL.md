# 美客多目录匹配与资料更正

## 任务与输入

- 自家实物品牌、型号、规格、GTIN、包数、配件和成色。
- 候选目录资料、原刊登与目录刊登的关联关系。
- 要修正的字段、真实证据、修改历史与当前状态。

先固定国家站、经营/物流模式、币种和观察日期。将事实、估算、假设与未知分开；缺关键资料时完成可确定部分，把受影响的判断留待补证。

## 工作流程

1. 逐字段比对实物和目录，任何关键身份差异都先阻止关联，不能只看主图或更高售价。
2. 画清目录产品、卖家报价和普通刊登的关系，确认哪些字段共享、哪些交易条件由自己控制。
3. 将资料错误与商品身份错误分开处理，提交有证据的更正建议；只保存接收回执不代表更新已生效。
4. 核对审核结果与买家端字段，并检查关联库存；如需暂停销售，确认相关刊登各自状态。

## 交付

交付身份匹配矩阵、修正材料、关联关系和实际生效状态。

遇到条件分支、字段设计和误判场景时读[操作手册](references/playbook.md)；核查来源实际支持范围和当期规则时读[证据与规则](references/evidence.md)。

## 执行范围

本包的流程、模板和算例为 M（模型综合），不表示已接入美客多或验证经营收益。只执行用户已授权的动作，已有授权不重复索取；变更需明确对象、前后值、实际能力与回读办法。工具不可用时交付方案和输入需求，不伪造已生效结果。
