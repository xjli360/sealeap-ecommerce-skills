# 美客多广告曝光损失诊断

## 任务与输入

- 当前活动/组、商品可投状态、库存与目录竞争信息。
- 赢得曝光、预算损失、排名损失及其同一时段口径。
- 花费、点击、归因订单、贡献和近期商品/目标ROAS变更。

先固定国家站、经营/物流模式、币种和观察日期。将事实、估算、假设与未知分开；缺关键资料时完成可确定部分，把受影响的判断留待补证。

## 工作流程

1. 先核资格、有效库存和广告组状态，确认报表不是时间窗未成熟或数据缺失。
2. 分开预算受限、排名竞争和低可用需求；核同口径指标定义，不把销售广告占比SOV当曝光份额。
3. 有足够曝光但点击弱时检查图、身份和报价；有点击却低成交时再查承诺、商品信息与交付，而不是只加钱。
4. 给出优先修复或有限预算/目标测试，附贡献边界；执行后在可比窗口回读，保留竞争与分发变化的限制。

## 交付

交付曝光不足的分支诊断、证据和有成本约束的修复或试验优先级。

遇到条件分支、字段设计和误判场景时读[操作手册](references/playbook.md)；核查来源实际支持范围和当期规则时读[证据与规则](references/evidence.md)。

## 执行范围

本包的流程、模板和算例为 M（模型综合），不表示已接入美客多或验证经营收益。只执行用户已授权的动作，已有授权不重复索取；变更需明确对象、前后值、实际能力与回读办法。工具不可用时交付方案和输入需求，不伪造已生效结果。
