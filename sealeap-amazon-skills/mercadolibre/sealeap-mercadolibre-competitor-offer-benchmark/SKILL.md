# 美客多同款报价与目录竞争分析

## 任务与输入

- 目标站点与商品真实身份：品牌、型号、规格、包数、配件和成色。
- 可比报价、运费、到货承诺、刊登类型、目录关联及观察位置/时间。
- 自家可承受价格底线、库存与履约能力。

先固定国家站、经营/物流模式、币种和观察日期。将事实、估算、假设与未知分开；缺关键资料时完成可确定部分，把受影响的判断留待补证。

## 工作流程

1. 冻结同款标准，逐项判断是否同品牌、同型号、同包装；不同规格另组，不把照片相似当同款。
2. 把商品价、运费、分期和实际交期放到同一买家条件下比较，保留卖家和目录两层身份。
3. 记录目录赢家与可见条件；换买家位置或变体后重新观察，不能从一个页面推断全站唯一赢家。
4. 形成价格、履约、库存或内容的候选改进，核贡献底线后提出测试；赢得目录不等于获得足够需求。

## 交付

交付可比报价表、目录观察边界和有利润约束的改进方案。

遇到条件分支、字段设计和误判场景时读[操作手册](references/playbook.md)；核查来源实际支持范围和当期规则时读[证据与规则](references/evidence.md)。

## 执行范围

本包的流程、模板和算例为 M（模型综合），不表示已接入美客多或验证经营收益。只执行用户已授权的动作，已有授权不重复索取；变更需明确对象、前后值、实际能力与回读办法。工具不可用时交付方案和输入需求，不伪造已生效结果。
